## Features

<CardGrid stagger>
    <Card title="Framework-agnostic" icon="puzzle">
        Standard Web Components that work with React, Vue, Angular, Svelte or plain HTML.
    </Card>
    <Card title="Themeable" icon="seti:css">
        Customize colors, radius, sizes & spacing through `--hx-*` design tokens.
    </Card>
    <Card title="Import only what you need" icon="rocket">
        Every component has its own entry point: `import "hexa-ui/button"`.
    </Card>
    <Card title="Dark mode built in" icon="moon">
        Toggle the `dark` class on `<html>`, or drop in `<hx-color-mode-button>`.
    </Card>
    <Card title="Built with Lit" icon="star">
        Lightweight, fast, reactive components powered by Lit and Shadow DOM.
    </Card>
    <Card title="Typed" icon="seti:typescript">
        Ships TypeScript declarations for every component.
    </Card>
</CardGrid>
