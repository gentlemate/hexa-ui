### Loading

`loading` shows a spinner in place of the icon and ignores clicks, while the button stays focusable. [`oui-form`](../form/) sets it on its submit buttons during a submission.

    code={`<oui-button loading>Saving</oui-button>

## API

### oui-button

#### Properties

| Property        | Attribute        | Type                                                                | Default     | Description                                                 |
| --------------- | ---------------- | ------------------------------------------------------------------- | ----------- | ----------------------------------------------------------- |
| `variant`       | `variant`        | `"primary" \| "secondary" \| "outline" \| "ghost" \| "destructive"` | `"primary"` | Visual style                                                |
| `type`          | `type`           | `"button" \| "submit" \| "reset"`                                   | `"button"`  | `submit` and `reset` act on the parent `<form>`             |
| `disabled`      | `disabled`       | `boolean`                                                           | `false`     | Disables the button                                         |
| `loading`       | `loading`        | `boolean`                                                           | `false`     | Shows a spinner in place of the icon and ignores clicks     |
| `square`        | `square`         | `boolean`                                                           | `false`     | Square button without horizontal padding, for an icon alone |
| `icon`          | —                | `IconNode`                                                          | —           | Lucide icon, set as a JS property                           |
| `iconPlacement` | `icon-placement` | `"left" \| "right"`                                                 | `"left"`    | Side of the icon relative to the label                      |
| `focusTarget`   | —                | `HTMLButtonElement`                                                 | —           | The inner element that receives the focus (read-only)       |

#### Slots

| Name      | Description                    |
| --------- | ------------------------------ |
| (default) | The button label (text, icon…) |

#### CSS custom properties

| Name                   | Default                      | Description        |
| ---------------------- | ---------------------------- | ------------------ |
| `--oui-height-button`  | `var(--oui-height-control)`  | Height             |
| `--oui-spacing-button` | `var(--oui-spacing-control)` | Horizontal padding |
| `--oui-radius-button`  | `var(--oui-radius-control)`  | Border radius      |

#### CSS parts

| Name   | Description                                      |
| ------ | ------------------------------------------------ |
| `base` | The inner `<button>` element                     |
| `icon` | The `oui-icon` rendered from the `icon` property |
