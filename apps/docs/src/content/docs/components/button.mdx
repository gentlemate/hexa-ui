## API

### Properties

| Property        | Attribute        | Type                                                                | Default     | Description                                                 |
| --------------- | ---------------- | ------------------------------------------------------------------- | ----------- | ----------------------------------------------------------- |
| `variant`       | `variant`        | `"primary" \| "secondary" \| "outline" \| "ghost" \| "destructive"` | `"primary"` | Visual style                                                |
| `type`          | `type`           | `"button" \| "submit" \| "reset"`                                   | `"button"`  | `submit` and `reset` act on the parent `<form>`             |
| `disabled`      | `disabled`       | `boolean`                                                           | `false`     | Disables the button                                         |
| `square`        | `square`         | `boolean`                                                           | `false`     | Square button without horizontal padding, for an icon alone |
| `icon`          | —                | `IconNode`                                                          | —           | Lucide icon, set as a JS property                           |
| `iconPlacement` | `icon-placement` | `"left" \| "right"`                                                 | `"left"`    | Side of the icon relative to the label                      |

### Slots

| Name      | Description                    |
| --------- | ------------------------------ |
| (default) | The button label (text, icon…) |

### CSS parts

| Name   | Description                                     |
| ------ | ----------------------------------------------- |
| `base` | The inner `<button>` element                    |
| `icon` | The `hx-icon` rendered from the `icon` property |
