## Examples

### Min, max and step

<Preview stack code={`<hx-slider label="Rating" value="2.5" min="0" max="5" step="0.5"></hx-slider>`} />

### Steps

`show-steps` shows a dot on the track at each step between `min` and `max`.

<Preview stack code={`<hx-slider label="Rating" value="3" max="10" show-steps></hx-slider>`} />

### Format

`format-options` takes the options of [`Intl.NumberFormat`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options), as JSON. With `"style": "percent"`, the position between `min` and `max` is displayed.

<Preview
    stack
    code={`<hx-slider label="Price" value="20" max="100" format-options='{"style":"currency","currency":"EUR"}'></hx-slider>
<hx-slider label="Opacity" value="0.8" max="1" step="0.01" format-options='{"style":"percent"}'></hx-slider>`}
/>

<Preview stack code={`<hx-slider label="Volume" value="50" disabled></hx-slider>`} />

### Input event

`input` fires while the thumb moves, `change` once it is released.

<Preview
    stack
    code={`<div class="flex flex-col gap-3">

</div>`}
/>

## Behavior

`value` is always a multiple of `step` from `min`, between `min` and `max`: a value set outside is snapped and clamped. The form receives `value` as a plain number string (`2.5`).

## Keyboard

<kbd>←</kbd> / <kbd>↓</kbd> and <kbd>→</kbd> / <kbd>↑</kbd> remove / add `step`, <kbd>Page Down</kbd> /
<kbd>Page Up</kbd> remove / add a tenth of the range, <kbd>Home</kbd> / <kbd>End</kbd> go to `min` / `max`.

## API

### hx-slider

#### Properties

| Property        | Attribute        | Type                       | Default | Description                                                                                                                                                |
| --------------- | ---------------- | -------------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`          | `name`           | `string`                   | `""`    | Name submitted with the form                                                                                                                               |
| `step`          | `step`           | `number`                   | `1`     | Interval between two values, also added or removed by the arrow keys                                                                                       |
| `showSteps`     | `show-steps`     | `boolean`                  | `false` | Shows a dot on the track at each step                                                                                                                      |
| `disabled`      | `disabled`       | `boolean`                  | `false` | Prevents user interaction                                                                                                                                  |
| `value`         | `value`          | `number`                   | `0`     | Current number                                                                                                                                             |
| `min`           | `min`            | `number`                   | `0`     | Smallest value                                                                                                                                             |
| `max`           | `max`            | `number`                   | `100`   | Largest value                                                                                                                                              |
| `label`         | `label`          | `string`                   | `""`    | Label displayed above the bar, next to the formatted value                                                                                                 |
| `locale`        | `locale`         | `string`                   | `""`    | Separators and digits of the displayed value; defaults to the closest `lang` attribute                                                                     |
| `formatOptions` | `format-options` | `Intl.NumberFormatOptions` | `{}`    | `Intl.NumberFormat` options of the displayed value, as JSON in the attribute. With `"style": "percent"`, the position between `min` and `max` is displayed |

#### Events

| Name     | Description                                                        |
| -------- | ------------------------------------------------------------------ |
| `input`  | The value changed, while dragging or from the keyboard             |
| `change` | The value changed, once the thumb is released or from the keyboard |

#### CSS custom properties

| Name                     | Default   | Description                              |
| ------------------------ | --------- | ---------------------------------------- |
| `--hx-height-slider`     | `0.5rem`  | Height of the track                      |
| `--hx-size-slider-thumb` | `1.25rem` | Size of the thumb                        |
| `--hx-radius-slider`     | `9999px`  | Border radius of the track and the thumb |

#### CSS parts

| Name    | Description                                 |
| ------- | ------------------------------------------- |
| `label` | The label                                   |
| `value` | The formatted value                         |
| `track` | The track                                   |
| `fill`  | The filled part of the track                |
| `step`  | A dot on the track, shown with `show-steps` |
| `thumb` | The draggable thumb                         |
