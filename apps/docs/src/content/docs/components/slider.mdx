## Import

```js
import "onent-ui/slider";
import "onent-ui/form-field";
```

The label, the description, the hint, the error and the formatted value come from [`oui-form-field`](../form-field/).

<Preview
    stack
    code={`<oui-form-field label="Volume">
    <oui-slider value="50"></oui-slider>
</oui-form-field>`}
/>

## Structure

```html
<oui-slider></oui-slider>
```

## Examples

### Min, max and step

<Preview
    stack
    code={`<oui-form-field label="Rating">
    <oui-slider value="2.5" min="0" max="5" step="0.5"></oui-slider>
</oui-form-field>`}
/>

### Steps

`show-steps` shows a dot on the track at each step between `min` and `max`.

<Preview
    stack
    code={`<oui-form-field label="Rating">
    <oui-slider value="2.5" min="0" max="5" step="0.5" show-steps></oui-slider>
</oui-form-field>`}
/>

### Format

`format-options` takes the options of [`Intl.NumberFormat`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options), as JSON. With `"style": "percent"`, the position between `min` and `max` is displayed.

<Preview
    stack
    code={`<oui-form-field label="Price">
    <oui-slider value="20" max="100" format-options='{"style":"currency","currency":"EUR"}'></oui-slider>
</oui-form-field>
<oui-form-field label="Opacity">
    <oui-slider value="0.8" max="1" step="0.01" format-options='{"style":"percent"}'></oui-slider>
</oui-form-field>`}
/>

### Disabled

<Preview stack code={`<oui-slider aria-label="Disabled" value="50" disabled></oui-slider>`} />

### Invalid

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`oui-form-field`](../form-field/#error).

<Preview stack code={`<oui-slider aria-label="Invalid" invalid></oui-slider>`} />

### Input event

`input` fires while the thumb moves, `change` once it is released.

<Preview
    stack
    code={`<div class="flex flex-col gap-3">
    <oui-form-field label="Brightness">
        <oui-slider value="50" oninput="this.nextElementSibling.style.opacity = this.value / 100"></oui-slider>
    </oui-form-field>
    <div class="bg-primary h-16 rounded-lg" style="opacity: 0.5"></div>
</div>`}
/>

## Behavior

`value` is always a multiple of `step` from `min`, between `min` and `max`: a value set outside is snapped and clamped. The form receives `value` as a plain number string (`2.5`).

## Keyboard

<kbd>←</kbd> / <kbd>↓</kbd> and <kbd>→</kbd> / <kbd>↑</kbd> remove / add `step`, <kbd>Page Down</kbd> /
<kbd>Page Up</kbd> remove / add a tenth of the range, <kbd>Home</kbd> / <kbd>End</kbd> go to `min` / `max`.

## API

### oui-slider

#### Properties

| Property        | Attribute        | Type                       | Default | Description                                                                                                                                                |
| --------------- | ---------------- | -------------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`          | `name`           | `string`                   | `""`    | Name submitted with the form                                                                                                                               |
| `step`          | `step`           | `number`                   | `1`     | Interval between two values, also added or removed by the arrow keys                                                                                       |
| `showSteps`     | `show-steps`     | `boolean`                  | `false` | Shows a dot on the track at each step                                                                                                                      |
| `disabled`      | `disabled`       | `boolean`                  | `false` | Prevents user interaction                                                                                                                                  |
| `invalid`       | `invalid`        | `boolean`                  | `false` | Marks the field as invalid without displaying a message                                                                                                    |
| `ariaLabel`     | `aria-label`     | `string \| null`           | `null`  | Accessible name of the field, set with the `aria-label` attribute                                                                                          |
| `focusTarget`   | —                | `HTMLElement`              | —       | The thumb, which holds the focus (read-only)                                                                                                               |
| `value`         | `value`          | `number`                   | `0`     | Current number                                                                                                                                             |
| `min`           | `min`            | `number`                   | `0`     | Smallest value                                                                                                                                             |
| `max`           | `max`            | `number`                   | `100`   | Largest value                                                                                                                                              |
| `locale`        | `locale`         | `string`                   | `""`    | Separators and digits of the displayed value; defaults to the closest `lang` attribute                                                                     |
| `formatOptions` | `format-options` | `Intl.NumberFormatOptions` | `{}`    | `Intl.NumberFormat` options of the displayed value, as JSON in the attribute. With `"style": "percent"`, the position between `min` and `max` is displayed |
| `valueText`     | —                | — (read-only)              | —       | The formatted value (read-only)                                                                                                                            |

#### Events

| Name               | Description                                                        |
| ------------------ | ------------------------------------------------------------------ |
| `input`            | The value changed, while dragging or from the keyboard             |
| `change`           | The value changed, once the thumb is released or from the keyboard |
| `oui-value-change` | `valueText` changed, by the user or from code                      |

#### CSS custom properties

| Name                        | Default                    | Description                |
| --------------------------- | -------------------------- | -------------------------- |
| `--oui-height-slider`       | `0.5rem`                   | Height of the track        |
| `--oui-size-slider-thumb`   | `1.25rem`                  | Size of the thumb          |
| `--oui-radius-slider`       | `var(--oui-radius-pill)`   | Border radius of the track |
| `--oui-radius-slider-thumb` | `var(--oui-radius-slider)` | Border radius of the thumb |

#### CSS parts

| Name    | Description                                 |
| ------- | ------------------------------------------- |
| `track` | The track                                   |
| `fill`  | The filled part of the track                |
| `step`  | A dot on the track, shown with `show-steps` |
| `thumb` | The draggable thumb                         |
