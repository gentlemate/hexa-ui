## Structure

```html
<oui-label></oui-label>
```

## Examples

### Required

`required` adds an asterisk after the text.

<Preview
    code={`<oui-checkbox id="terms"></oui-checkbox>
<oui-label for="terms" required>Accept the terms</oui-label>`}
/>

## Usage

`for` takes the `id` of the control. A click on the label focuses and clicks the control, and the label gives the control its accessible name. To add messages, use [`oui-form-field`](../form-field/).

## API

### oui-label

#### Properties

| Property   | Attribute  | Type      | Default | Description                     |
| ---------- | ---------- | --------- | ------- | ------------------------------- |
| `htmlFor`  | `for`      | `string`  | `""`    | `id` of the control it labels   |
| `required` | `required` | `boolean` | `false` | Adds an asterisk after the text |

#### Slots

| Name      | Description    |
| --------- | -------------- |
| (default) | The label text |

#### CSS parts

| Name   | Description                 |
| ------ | --------------------------- |
| `base` | The inner `<label>` element |
