### Size

`size` sets the width of a `left` or `right` drawer and the height of a `top` or `bottom` drawer.

| `size` | Width (`left`, `right`) | Height (`top`, `bottom`) |
| ------ | ----------------------- | ------------------------ |
| `xs`   | 16rem                   | 20% of the screen        |
| `sm`   | 24rem                   | 35% of the screen        |
| `md`   | 36rem                   | 50% of the screen        |
| `lg`   | 56rem                   | 65% of the screen        |
| `xl`   | 80rem                   | 80% of the screen        |
| `full` | 100%                    | 100%                     |

Without `size`, the width is `--hx-width-drawer` (36rem, like `md`) and the height `--hx-height-drawer` (the height of the content). Except for `full`, the drawer stays within `--hx-max-width-drawer` and `--hx-max-height-drawer`.

### Resizable

`resizable` adds a handle on the inner edge. Drag it, or focus it and use the arrow keys (<kbd>Home</kbd> and <kbd>End</kbd> jump to the bounds). The size stays between `--hx-min-width-drawer` and `--hx-max-width-drawer` on the sides, `--hx-min-height-drawer` and `--hx-max-height-drawer` at the top and bottom. `hx-resize` gives the new size to save it.

## Usage

The drawer closes on <kbd>Escape</kbd>, on a backdrop click (unless `persistent`), with the close button and on a click on any element with a `data-close` attribute. All of them go through `hide()`, so `hx-hide` can cancel them.

While open, the rest of the page is inert and does not scroll. On close, the focus returns to the element that had it before opening. The title and the description label and describe the dialog; without a title, `label` does.

## API

### hx-drawer

#### Properties

| Property       | Attribute       | Type                                             | Default     | Description                                                                                                                                                                                   |
| -------------- | --------------- | ------------------------------------------------ | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `variant`      | `variant`       | `"default" \| "secondary"`                       | `"default"` | Visual style. `secondary` leaves a margin on both sides along the edge and rounds the inner corners                                                                                           |
| `placement`    | `placement`     | `"top" \| "right" \| "bottom" \| "left"`         | `"right"`   | Edge of the screen the drawer slides in from                                                                                                                                                  |
| `size`         | `size`          | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "full"` | —           | Width with `left` and `right` (`xs` 16rem to `xl` 80rem), height with `top` and `bottom` (`xs` 20% to `xl` 80% of the screen). Without it, `--hx-width-drawer` and `--hx-height-drawer` apply |
| `resizable`    | `resizable`     | `boolean`                                        | `false`     | Adds a handle on the inner edge to resize the drawer with the pointer or the arrow keys                                                                                                       |
| `label`        | `label`         | `string`                                         | `""`        | Accessible name of the dialog when there is no title                                                                                                                                          |
| `persistent`   | `persistent`    | `boolean`                                        | `false`     | Ignores backdrop clicks                                                                                                                                                                       |
| `withoutClose` | `without-close` | `boolean`                                        | `false`     | Hides the close button                                                                                                                                                                        |
| `open`         | `open`          | `boolean`                                        | `false`     | Whether it is open. Setting it directly skips `hx-show` / `hx-hide`                                                                                                                           |

#### Methods

| Name     | Description                 |
| -------- | --------------------------- |
| `show()` | Opens it (fires `hx-show`)  |
| `hide()` | Closes it (fires `hx-hide`) |

#### Events

| Name            | Description                                                                                                                                                      |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hx-show`       | The drawer is about to open. Cancelable                                                                                                                          |
| `hx-after-show` | The drawer is open and its enter animation finished                                                                                                              |
| `hx-hide`       | The drawer is about to close (Escape, backdrop, close button, `data-close`…). Cancelable                                                                         |
| `hx-after-hide` | The drawer is closed and its exit animation finished                                                                                                             |
| `hx-resize`     | The drawer was resized, once the handle is released or from the keyboard. `detail.size` is the new width (`left`, `right`) or height (`top`, `bottom`) in pixels |

#### Slots

| Name      | Description                                                                                                  |
| --------- | ------------------------------------------------------------------------------------------------------------ |
| `trigger` | The element that opens the drawer on click (e.g. an `hx-button`). Optional: `show()` and `open` also open it |
| (default) | The drawer sections: `hx-drawer-header`, `hx-drawer-content` and `hx-drawer-footer`                          |

#### CSS custom properties

| Name                     | Default                   | Description                                                                                                                |
| ------------------------ | ------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `--hx-spacing-drawer`    | `var(--hx-spacing-panel)` | Padding                                                                                                                    |
| `--hx-radius-drawer`     | `var(--hx-radius-panel)`  | Border radius of the inner corners with `secondary`                                                                        |
| `--hx-inset-drawer`      | `1rem`                    | Margin on both sides along the edge with `secondary`. `auto` sizes the drawer to its content and centers it along the edge |
| `--hx-width-drawer`      | `36rem`                   | Width with `left` and `right`                                                                                              |
| `--hx-min-width-drawer`  | `16rem`                   | Minimum width when resizing                                                                                                |
| `--hx-max-width-drawer`  | `calc(100% - 3rem)`       | Maximum width                                                                                                              |
| `--hx-height-drawer`     | `auto`                    | Height with `top` and `bottom`                                                                                             |
| `--hx-min-height-drawer` | `10rem`                   | Minimum height when resizing                                                                                               |
| `--hx-max-height-drawer` | `calc(100% - 3rem)`       | Maximum height                                                                                                             |

#### CSS parts

| Name           | Description                                                           |
| -------------- | --------------------------------------------------------------------- |
| `base`         | The `<dialog>` element (`::part(base)::backdrop` styles the backdrop) |
| `close-button` | The close button (not rendered with `without-close`)                  |
| `handle`       | The resize handle (rendered with `resizable`)                         |

| --------- | ---------------------------------------------------------------------------------- |
