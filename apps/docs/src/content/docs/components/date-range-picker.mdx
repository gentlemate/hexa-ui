```js

```

The label, the description, the hint and the error come from [`hx-form-field`](../form-field/).

### Change event

`change` fires once both ends of the range are picked, after `start` and `end` are updated.

<Preview
    stack
    code={`<hx-form-field label="Date range" hint="Thursday 1 January – Thursday 31 December 2026">
    <hx-date-range-picker
        start="2026-01-01"
        end="2026-12-31"
        onchange="this.parentElement.hint = new Intl.DateTimeFormat('en-GB', { dateStyle: 'full' }).formatRange(new Date(this.start + 'T00:00'), new Date(this.end + 'T00:00'))"
    ></hx-date-range-picker>
</hx-form-field>`}
/>

## Behavior

`start`, `end`, `min` and `max` are always in the `YYYY-MM-DD` format (like `<input type="date">`), whatever the `locale`: it only changes how the range is displayed.

The first click picks one end of the range and the second one the other end, in any order; hovering previews the range. `input` / `change` fire once both ends are picked, then the calendar closes. <kbd>Escape</kbd> after the first click cancels it.

## Keyboard

<kbd>↓</kbd> / <kbd>↑</kbd> on the trigger open the calendar. The calendar keys then apply (see
[Calendar](../calendar/#keyboard)); <kbd>Enter</kbd> / <kbd>Space</kbd> pick each end of the range. <kbd>Escape</kbd>
cancels a range in progress, otherwise closes the calendar.

## API

### hx-date-range-picker

#### Properties

| Property      | Attribute      | Type                                                                                                                                                                 | Default          | Description                                                                                  |
| ------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------------- |
| `startName`   | `start-name`   | `string`                                                                                                                                                             | `""`             | Name of the first date submitted with the form                                               |
| `endName`     | `end-name`     | `string`                                                                                                                                                             | `""`             | Name of the last date submitted with the form                                                |
| `start`       | `start`        | `string`                                                                                                                                                             | `""`             | First date of the selected range, as `YYYY-MM-DD`                                            |
| `end`         | `end`          | `string`                                                                                                                                                             | `""`             | Last date of the selected range, as `YYYY-MM-DD`                                             |
| `min`         | `min`          | `string`                                                                                                                                                             | `""`             | Earliest selectable date, as `YYYY-MM-DD`                                                    |
| `max`         | `max`          | `string`                                                                                                                                                             | `""`             | Latest selectable date, as `YYYY-MM-DD`                                                      |
| `locale`      | `locale`       | `string`                                                                                                                                                             | `""`             | Language of the displayed date and of the calendar; defaults to the closest `lang` attribute |
| `dateStyle`   | `date-style`   | `"full" \| "long" \| "medium" \| "short"`                                                                                                                            | `"medium"`       | Format of the displayed date                                                                 |
| `monthSelect` | `month-select` | `boolean`                                                                                                                                                            | `false`          | Shows the month of the calendar as a select                                                  |
| `yearSelect`  | `year-select`  | `boolean`                                                                                                                                                            | `false`          | Shows the year of the calendar as a select                                                   |
| `placement`   | `placement`    | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom-start"` | Position of the calendar relative to the trigger                                             |
| `distance`    | `distance`     | `number`                                                                                                                                                             | `4`              | Gap in pixels between the trigger and the calendar                                           |
| `placeholder` | `placeholder`  | `string`                                                                                                                                                             | `""`             | Text shown when nothing is selected                                                          |
| `disabled`    | `disabled`     | `boolean`                                                                                                                                                            | `false`          | Prevents user interaction                                                                    |
| `required`    | `required`     | `boolean`                                                                                                                                                            | `false`          | Marks the field as required for form validation                                              |
| `invalid`     | `invalid`      | `boolean`                                                                                                                                                            | `false`          | Marks the field as invalid without displaying a message                                      |
| `ariaLabel`   | `aria-label`   | `string \| null`                                                                                                                                                     | `null`           | Accessible name of the field, set with the `aria-label` attribute                            |
| `focusTarget` | —              | `HTMLButtonElement`                                                                                                                                                  | —                | The inner element that receives the focus (read-only)                                        |
| `open`        | `open`         | `boolean`                                                                                                                                                            | `false`          | Whether it is open. Setting it directly skips `hx-show` / `hx-hide`                          |

#### Methods

| Name     | Description                 |
| -------- | --------------------------- |
| `show()` | Opens it (fires `hx-show`)  |
| `hide()` | Closes it (fires `hx-hide`) |

#### Events

| Name            | Description                                            |
| --------------- | ------------------------------------------------------ |
| `input`         | The user selected another range                        |
| `change`        | The user selected another range                        |
| `hx-show`       | The calendar is about to open. Cancelable              |
| `hx-after-show` | The calendar is open and its enter animation finished  |
| `hx-hide`       | The calendar is about to close. Cancelable             |
| `hx-after-hide` | The calendar is closed and its exit animation finished |

#### CSS custom properties

| Name                             | Default                   | Description                                                                 |
| -------------------------------- | ------------------------- | --------------------------------------------------------------------------- |
| `--hx-height-date-range-picker`  | `var(--hx-height-field)`  | Height of the trigger                                                       |
| `--hx-spacing-date-range-picker` | `var(--hx-spacing-field)` | Horizontal padding of the trigger                                           |
| `--hx-radius-date-range-picker`  | `var(--hx-radius-field)`  | Border radius of the trigger                                                |
| `--hx-spacing-calendar`          | `var(--hx-spacing-popup)` | Padding around the calendar                                                 |
| `--hx-size-calendar-day`         | `2.25rem`                 | Width and height of the day cells, and height of the month and year selects |

#### CSS parts

| Name       | Description                            |
| ---------- | -------------------------------------- |
| `trigger`  | The button showing the selected range  |
| `value`    | The selected range, or the placeholder |
| `icon`     | The calendar icon of the trigger       |
| `popup`    | The panel holding the calendar         |
| `calendar` | The `hx-range-calendar`                |
