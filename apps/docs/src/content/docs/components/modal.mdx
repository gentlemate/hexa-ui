## Examples

### Size

`size` sets the width of the modal.

| `size` | Width |
| ------ | ----- |
| `xs`   | 16rem |
| `sm`   | 24rem |
| `md`   | 36rem |
| `lg`   | 56rem |
| `xl`   | 80rem |
| `full` | 100%  |

Without `size`, the width is `--hx-width-modal` (36rem, like `md`) and the height `--hx-height-modal` (the height of the content). Except for `full`, the modal stays within `--hx-max-width-modal` and `--hx-max-height-modal`.

### Resizable

`resizable` makes the corners resize the modal in every direction, without visible handles. `resizable-x` adds handles on the left and right edges to resize the width only, `resizable-y` on the top and bottom edges to resize the height only. The modal stays centered and grows on both sides. Drag a corner or a handle, or focus the bottom right corner, the right handle or the bottom handle and use the arrow keys (<kbd>Home</kbd> and <kbd>End</kbd> jump to the bounds). The size stays between `--hx-min-width-modal` and `--hx-max-width-modal`, `--hx-min-height-modal` and `--hx-max-height-modal`. `hx-resize` gives the new size to save it.

### Persistent

`persistent` ignores backdrop clicks and `without-close` removes the close button: the modal only closes through its actions or <kbd>Escape</kbd>.

## Usage

The modal closes on <kbd>Escape</kbd>, on a backdrop click (unless `persistent`), with the close button and on a click on any element with a `data-close` attribute. All of them go through `hide()`, so `hx-hide` can cancel them.

While open, the rest of the page is inert and does not scroll. On close, the focus returns to the element that had it before opening. The title and the description label and describe the dialog; without a title, `label` does.

## API

### hx-modal

#### Properties

| Property       | Attribute       | Type                                             | Default | Description                                                                                                        |
| -------------- | --------------- | ------------------------------------------------ | ------- | ------------------------------------------------------------------------------------------------------------------ |
| `size`         | `size`          | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "full"` | —       | Width, from `xs` 16rem to `xl` 80rem. `full` covers the whole screen. Without it, `--hx-width-modal` applies       |
| `resizable`    | `resizable`     | `boolean`                                        | `false` | Makes the corners resize the width and the height with the pointer, or the arrow keys from the bottom right corner |
| `resizableX`   | `resizable-x`   | `boolean`                                        | `false` | Adds handles on the left and right edges to resize the width with the pointer or the arrow keys                    |
| `resizableY`   | `resizable-y`   | `boolean`                                        | `false` | Adds handles on the top and bottom edges to resize the height with the pointer or the arrow keys                   |
| `label`        | `label`         | `string`                                         | `""`    | Accessible name of the dialog when there is no title                                                               |
| `persistent`   | `persistent`    | `boolean`                                        | `false` | Ignores backdrop clicks                                                                                            |
| `withoutClose` | `without-close` | `boolean`                                        | `false` | Hides the close button                                                                                             |
| `open`         | `open`          | `boolean`                                        | `false` | Whether it is open. Setting it directly skips `hx-show` / `hx-hide`                                                |

#### Methods

| Name     | Description                 |
| -------- | --------------------------- |
| `show()` | Opens it (fires `hx-show`)  |
| `hide()` | Closes it (fires `hx-hide`) |

#### Events

| Name            | Description                                                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `hx-show`       | The modal is about to open. Cancelable                                                                                               |
| `hx-after-show` | The modal is open and its enter animation finished                                                                                   |
| `hx-hide`       | The modal is about to close (Escape, backdrop, close button, `data-close`…). Cancelable                                              |
| `hx-after-hide` | The modal is closed and its exit animation finished                                                                                  |
| `hx-resize`     | The modal was resized, once a handle is released or from the keyboard. `detail.width` and `detail.height` are the new size in pixels |

#### Slots

| Name      | Description                                                                                                 |
| --------- | ----------------------------------------------------------------------------------------------------------- |
| `trigger` | The element that opens the modal on click (e.g. an `hx-button`). Optional: `show()` and `open` also open it |
| (default) | The modal sections: `hx-modal-header`, `hx-modal-content` and `hx-modal-footer`                             |

#### CSS custom properties

| Name                    | Default                   | Description                  |
| ----------------------- | ------------------------- | ---------------------------- |
| `--hx-spacing-modal`    | `var(--hx-spacing-panel)` | Padding                      |
| `--hx-radius-modal`     | `var(--hx-radius-panel)`  | Border radius                |
| `--hx-width-modal`      | `36rem`                   | Width                        |
| `--hx-min-width-modal`  | `16rem`                   | Minimum width when resizing  |
| `--hx-max-width-modal`  | `calc(100% - 2rem)`       | Maximum width                |
| `--hx-height-modal`     | `fit-content`             | Height                       |
| `--hx-min-height-modal` | `10rem`                   | Minimum height when resizing |
| `--hx-max-height-modal` | `calc(100% - 2rem)`       | Maximum height               |

#### CSS parts

| Name           | Description                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------- |
| `base`         | The `<dialog>` element (`::part(base)::backdrop` styles the backdrop)                       |
| `close-button` | The close button (not rendered with `without-close`)                                        |
| `handle`       | The resize handles and corners (rendered with `resizable`, `resizable-x` and `resizable-y`) |

### hx-modal-header

#### Slots

| Name      | Description                                                                  |
| --------- | ---------------------------------------------------------------------------- |
| (default) | The `hx-modal-title` and `hx-modal-description` elements, or a custom header |

### hx-modal-title

#### Slots

| Name      | Description                           |
| --------- | ------------------------------------- |
| (default) | The modal title. It labels the dialog |

### hx-modal-description

#### Slots

| Name      | Description                                           |
| --------- | ----------------------------------------------------- |
| (default) | A short text under the title. It describes the dialog |

### hx-modal-content

#### Slots

| Name      | Description                                     |
| --------- | ----------------------------------------------- |
| (default) | The modal content, scrollable when it overflows |

### hx-modal-footer

#### Slots

| Name      | Description                                                                      |
| --------- | -------------------------------------------------------------------------------- |
| (default) | The modal footer (actions…). Elements with `data-close` close the modal on click |
