    <oui-modal-header>

## Examples

### Size

`size` sets the width of the modal.

| `size` | Width |
| ------ | ----- |
| `xs`   | 16rem |
| `sm`   | 24rem |
| `md`   | 36rem |
| `lg`   | 56rem |
| `xl`   | 80rem |
| `full` | 100%  |

Without `size`, the width is `--oui-width-modal` (36rem, like `md`) and the height `--oui-height-modal` (the height of the content). The modal never exceeds the screen.

### Resizable

`resizable` makes the corners resize the modal in every direction, without visible handles. `resizable-x` adds handles on the left and right edges to resize the width only, `resizable-y` on the top and bottom edges to resize the height only. The modal stays centered and grows on both sides. Drag a corner or a handle, or focus the bottom right corner, the right handle or the bottom handle and use the arrow keys (<kbd>Home</kbd> and <kbd>End</kbd> jump to the bounds). The size stays above `--oui-min-width-modal` and `--oui-min-height-modal`, and within the screen. `oui-resize` gives the new size to save it.

### Movable

`movable` lets the modal be dragged by its empty areas: around the sections, the header (title and description included) and the footer. The content and the interactive elements are not grab areas, so text stays selectable and fields usable. Without a header, the space above the content and the close button still works. The modal stays within the screen and keeps its position when reopened. `oui-move` gives its offset from the center.

### Persistent

`persistent` ignores backdrop clicks and `without-close` removes the close button: the modal only closes through its actions or <kbd>Escape</kbd>.

## Usage

The modal closes on <kbd>Escape</kbd>, on a backdrop click (unless `persistent`), with the close button and on a click on any element with a `data-close` attribute. All of them go through `hide()`, so `oui-hide` can cancel them.

While open, the rest of the page is inert and does not scroll. On close, the focus returns to the element that had it before opening. The title and the description label and describe the dialog; without a title, `label` does.

## API

### oui-modal

#### Properties

| Property       | Attribute       | Type                                             | Default | Description                                                                                                                                                                                                     |
| -------------- | --------------- | ------------------------------------------------ | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `size`         | `size`          | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "full"` | —       | Width, from `xs` 16rem to `xl` 80rem. `full` covers the whole screen. Without it, `--oui-width-modal` applies                                                                                                   |
| `resizable`    | `resizable`     | `boolean`                                        | `false` | Makes the corners resize the width and the height with the pointer, or the arrow keys from the bottom right corner                                                                                              |
| `resizableX`   | `resizable-x`   | `boolean`                                        | `false` | Adds handles on the left and right edges to resize the width with the pointer or the arrow keys                                                                                                                 |
| `resizableY`   | `resizable-y`   | `boolean`                                        | `false` | Adds handles on the top and bottom edges to resize the height with the pointer or the arrow keys                                                                                                                |
| `movable`      | `movable`       | `boolean`                                        | `false` | Lets the modal be dragged by its empty areas: around the sections, the header (title and description included) and the footer, not the content. It stays within the screen and keeps its position when reopened |
| `label`        | `label`         | `string`                                         | `""`    | Accessible name of the dialog when there is no title                                                                                                                                                            |
| `persistent`   | `persistent`    | `boolean`                                        | `false` | Ignores backdrop clicks                                                                                                                                                                                         |
| `withoutClose` | `without-close` | `boolean`                                        | `false` | Hides the close button                                                                                                                                                                                          |
| `modeless`     | `modeless`      | `boolean`                                        | `false` | Opens without a backdrop and keeps the rest of the page interactive and scrollable                                                                                                                              |
| `open`         | `open`          | `boolean`                                        | `false` | Whether it is open. Setting it directly skips `oui-show` / `oui-hide`                                                                                                                                           |

#### Methods

| Name     | Description                  |
| -------- | ---------------------------- |
| `show()` | Opens it (fires `oui-show`)  |
| `hide()` | Closes it (fires `oui-hide`) |

#### Events

| Name             | Description                                                                                                                          |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `oui-move`       | The modal was moved, once released. `detail.x` and `detail.y` are its offset from the center in pixels                               |
| `oui-show`       | The modal is about to open. Cancelable                                                                                               |
| `oui-after-show` | The modal is open and its enter animation finished                                                                                   |
| `oui-hide`       | The modal is about to close (Escape, backdrop, close button, `data-close`…). Cancelable                                              |
| `oui-after-hide` | The modal is closed and its exit animation finished                                                                                  |
| `oui-resize`     | The modal was resized, once a handle is released or from the keyboard. `detail.width` and `detail.height` are the new size in pixels |

#### Slots

| Name      | Description                                                                                                  |
| --------- | ------------------------------------------------------------------------------------------------------------ |
| `trigger` | The element that opens the modal on click (e.g. an `oui-button`). Optional: `show()` and `open` also open it |
| (default) | The modal sections: `oui-modal-header`, `oui-modal-content` and `oui-modal-footer`                           |

#### CSS custom properties

| Name                     | Default                    | Description                  |
| ------------------------ | -------------------------- | ---------------------------- |
| `--oui-spacing-modal`    | `var(--oui-spacing-panel)` | Padding                      |
| `--oui-radius-modal`     | `var(--oui-radius-panel)`  | Border radius                |
| `--oui-width-modal`      | `36rem`                    | Width                        |
| `--oui-min-width-modal`  | `16rem`                    | Minimum width when resizing  |
| `--oui-height-modal`     | `fit-content`              | Height                       |
| `--oui-min-height-modal` | `10rem`                    | Minimum height when resizing |

#### CSS parts

| Name           | Description                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------- |
| `base`         | The `<dialog>` element (`::part(base)::backdrop` styles the backdrop)                       |
| `close-button` | The close button (not rendered with `without-close`)                                        |
| `handle`       | The resize handles and corners (rendered with `resizable`, `resizable-x` and `resizable-y`) |

### oui-modal-header

#### Slots

| Name      | Description                                                                    |
| --------- | ------------------------------------------------------------------------------ |
| (default) | The `oui-modal-title` and `oui-modal-description` elements, or a custom header |

### oui-modal-title

#### Slots

| Name      | Description                           |
| --------- | ------------------------------------- |
| (default) | The modal title. It labels the dialog |

### oui-modal-description

#### Slots

| Name      | Description                                           |
| --------- | ----------------------------------------------------- |
| (default) | A short text under the title. It describes the dialog |

### oui-modal-content

#### Slots

| Name      | Description                                     |
| --------- | ----------------------------------------------- |
| (default) | The modal content, scrollable when it overflows |

### oui-modal-footer

#### Slots

| Name      | Description                                                                      |
| --------- | -------------------------------------------------------------------------------- |
| (default) | The modal footer (actions…). Elements with `data-close` close the modal on click |
