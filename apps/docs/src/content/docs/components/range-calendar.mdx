## Examples

### Min and max

Days outside the range are disabled, and so are the navigation buttons that would leave it.

<Preview code={`<hx-range-calendar min="2026-01-01" max="2026-12-31"></hx-range-calendar>`} />

### Month and year selects

`month-select` and `year-select` turn the month and the year of the heading into selects, independently. Without `min` / `max`, the years go from 100 years before to 100 years after today.

<Preview
    code={`<hx-range-calendar month-select></hx-range-calendar>
<hx-range-calendar year-select></hx-range-calendar>
<hx-range-calendar month-select year-select></hx-range-calendar>`}
/>

### Locale

Month and weekday names, and the first day of the week, follow `locale`, or the closest `lang` attribute.

<Preview code={`<hx-range-calendar locale="en-US"></hx-range-calendar>`} />

### Change event

`change` fires once both ends of the range are picked, after `start` and `end` are updated.

<Preview
    code={`<div>
    <hx-range-calendar
        start="2026-10-12"
        end="2026-10-21"
        onchange="this.nextElementSibling.textContent = new Intl.DateTimeFormat('en-GB', { dateStyle: 'full' }).formatRange(new Date(this.start + 'T00:00'), new Date(this.end + 'T00:00'))"
    ></hx-range-calendar>
    <p class="mt-2 text-sm">Monday 12 October – Wednesday 21 October 2026</p>
</div>`}
/>

## Behavior

`start`, `end`, `min` and `max` are always in the `YYYY-MM-DD` format, whatever the `locale`.

The first click picks one end of the range and the second one the other end, in any order; hovering (or moving the focus with the keyboard) previews the range. <kbd>Escape</kbd> after the first click cancels it.

## Keyboard

Same keys as [Calendar](../calendar/#keyboard); <kbd>Enter</kbd> / <kbd>Space</kbd> pick each end of the range.

## API

### hx-range-calendar

#### Properties

| Property      | Attribute      | Type                | Default | Description                                                                         |
| ------------- | -------------- | ------------------- | ------- | ----------------------------------------------------------------------------------- |
| `start`       | `start`        | `string`            | `""`    | First date of the selected range, as `YYYY-MM-DD`                                   |
| `end`         | `end`          | `string`            | `""`    | Last date of the selected range, as `YYYY-MM-DD`                                    |
| `min`         | `min`          | `string`            | `""`    | Earliest selectable date, as `YYYY-MM-DD`                                           |
| `max`         | `max`          | `string`            | `""`    | Latest selectable date, as `YYYY-MM-DD`                                             |
| `locale`      | `locale`       | `string`            | `""`    | Language of the month and weekday names; defaults to the closest `lang` attribute   |
| `monthSelect` | `month-select` | `boolean`           | `false` | Shows the month as a select                                                         |
| `yearSelect`  | `year-select`  | `boolean`           | `false` | Shows the year as a select, from `min` to `max` (100 years around today by default) |
| `focusTarget` | —              | `HTMLButtonElement` | —       | The day of the grid that receives the focus (read-only)                             |

#### Events

| Name     | Description                                                 |
| -------- | ----------------------------------------------------------- |
| `change` | The user selected another range (once both ends are picked) |

#### CSS custom properties

| Name                     | Default   | Description                                                                 |
| ------------------------ | --------- | --------------------------------------------------------------------------- |
| `--hx-size-calendar-day` | `2.25rem` | Width and height of the day cells, and height of the month and year selects |

#### CSS parts

| Name           | Description                                                                         |
| -------------- | ----------------------------------------------------------------------------------- |
| `header`       | The month heading and the navigation buttons                                        |
| `heading`      | The displayed month and year (visually hidden with `month-select` or `year-select`) |
| `month-select` | The `hx-select` of the month                                                        |
| `year-select`  | The `hx-select` of the year                                                         |
| `previous`     | The previous month button                                                           |
| `next`         | The next month button                                                               |
| `grid`         | The table of days                                                                   |
| `weekday`      | A weekday column header                                                             |
| `day`          | A day button                                                                        |
