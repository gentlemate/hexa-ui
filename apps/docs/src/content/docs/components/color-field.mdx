## Examples

### Format

The field accepts hex, `rgb()`, `hsl()` and `oklch()` colors, whatever its `format`. Once the user edits it, the color is converted to `format`: `hex` (default), `rgb`, `hsl` or `oklch`. Try typing `rgb(43 127 255)` in these fields.

<Preview
    stack
    code={`<hx-form-field label="HEX">
    <hx-color-field value="#2b7fff"></hx-color-field>
</hx-form-field>
<hx-form-field label="RGB">
    <hx-color-field format="rgb" value="rgb(43 127 255)"></hx-color-field>
</hx-form-field>
<hx-form-field label="HSL">
    <hx-color-field format="hsl" value="hsl(216 100% 58%)"></hx-color-field>
</hx-form-field>
<hx-form-field label="OKLCH">
    <hx-color-field format="oklch" value="oklch(0.623 0.214 259.815)"></hx-color-field>
</hx-form-field>`}
/>

### Invalid

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`hx-form-field`](../form-field/#error).

<Preview stack code={`<hx-color-field aria-label="Invalid" invalid></hx-color-field>`} />

### Form field

In a form, [`hx-form-field`](../form-field/) adds the label, the hint and the error message.

<Preview
    stack
    code={`<hx-form-field label="Brand" hint="Hex, rgb(), hsl() or oklch().">
    <hx-color-field placeholder="#000000"></hx-color-field>
</hx-form-field>
<hx-form-field label="Destructive" error="This color is not accessible.">
    <hx-color-field value="#fb2c36"></hx-color-field>
</hx-form-field>`}
/>

## Behavior

The value changes on blur or with the Enter key, not at each keystroke. A text that is not a color is discarded and the previous value comes back, and an empty text clears the value. The `#` of a hex color is optional.

`value` is kept as is until the user edits it, so an `oklch()` color outside the sRGB gamut is not altered by displaying it. Editing it brings it back into sRGB.

## API

### hx-color-field

#### Properties

| Property      | Attribute     | Type                                 | Default | Description                                                                                       |
| ------------- | ------------- | ------------------------------------ | ------- | ------------------------------------------------------------------------------------------------- |
| `name`        | `name`        | `string`                             | `""`    | Name submitted with the form                                                                      |
| `value`       | `value`       | `string`                             | `""`    | Current color, as a hex, `rgb()`, `hsl()` or `oklch()` string; kept as is until the user edits it |
| `format`      | `format`      | `"hex" \| "rgb" \| "hsl" \| "oklch"` | `"hex"` | Format of the value once the user edits it                                                        |
| `alpha`       | `alpha`       | `boolean`                            | `false` | Keeps the transparency of the typed color                                                         |
| `placeholder` | `placeholder` | `string`                             | `""`    | Text shown when the field is empty                                                                |
| `disabled`    | `disabled`    | `boolean`                            | `false` | Prevents user interaction                                                                         |
| `required`    | `required`    | `boolean`                            | `false` | Marks the field as required for form validation                                                   |
| `invalid`     | `invalid`     | `boolean`                            | `false` | Marks the field as invalid without displaying a message                                           |
| `ariaLabel`   | `aria-label`  | `string \| null`                     | `null`  | Accessible name of the field, set with the `aria-label` attribute                                 |
| `focusTarget` | —             | `HTMLInputElement`                   | —       | The inner element that receives the focus (read-only)                                             |

#### Events

| Name     | Description                                      |
| -------- | ------------------------------------------------ |
| `input`  | The value changed, on blur or with the Enter key |
| `change` | The value changed, on blur or with the Enter key |

#### CSS custom properties

| Name                       | Default                   | Description                 |
| -------------------------- | ------------------------- | --------------------------- |
| `--hx-height-color-field`  | `var(--hx-height-field)`  | Height                      |
| `--hx-spacing-color-field` | `var(--hx-spacing-field)` | Horizontal padding          |
| `--hx-radius-color-field`  | `var(--hx-radius-field)`  | Border radius               |
| `--hx-size-color-swatch`   | `1.25rem`                 | Size of the swatch          |
| `--hx-radius-color-swatch` | `var(--hx-radius-pill)`   | Border radius of the swatch |

#### CSS parts

| Name      | Description                 |
| --------- | --------------------------- |
| `control` | The inner `<input>` element |
| `swatch`  | The preview of the color    |
