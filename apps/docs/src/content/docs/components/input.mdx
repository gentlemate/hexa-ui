## Import

```js
import "hexa-ui/input";
import "hexa-ui/form-field";
```

The label, the description, the hint and the error come from [`hx-form-field`](../form-field/).

<Preview
    stack
    code={`<hx-form-field label="Email">
    <hx-input type="email" placeholder="you@example.com"></hx-input>
</hx-form-field>`}
/>

## Structure

```html
<hx-input></hx-input>
```

## Examples

### Disabled

<Preview stack code={`<hx-input aria-label="Disabled" value="John Doe" disabled></hx-input>`} />

### Invalid

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`hx-form-field`](../form-field/#error).

<Preview stack code={`<hx-input aria-label="Invalid" invalid></hx-input>`} />

### Input event

`input` fires on each keystroke, after `value` is updated.

<Preview
    stack
    code={`<hx-form-field label="Name" hint="Hello!">
    <hx-input oninput="this.parentElement.hint = this.value ? 'Hello, ' + this.value + '!' : 'Hello!'"></hx-input>
</hx-form-field>`}
/>

### Form field

In a form, [`hx-form-field`](../form-field/) adds the label, the hint and the error message.

<Preview
    stack
    code={`<hx-form-field label="Password" hint="Should not be disclosed.">
    <hx-input type="password"></hx-input>
</hx-form-field>
<hx-form-field label="Login" error="This login is already used." required>
    <hx-input value="admin"></hx-input>
</hx-form-field>`}
/>

## API

### hx-input

#### Properties

| Property      | Attribute     | Type                                                                        | Default  | Description                                                       |
| ------------- | ------------- | --------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------- |
| `name`        | `name`        | `string`                                                                    | `""`     | Name submitted with the form                                      |
| `value`       | `value`       | `string`                                                                    | `""`     | Current value                                                     |
| `type`        | `type`        | `"text" \| "email" \| "password" \| "search" \| "tel" \| "url" \| "number"` | `"text"` | Type of the inner `<input>`                                       |
| `placeholder` | `placeholder` | `string`                                                                    | `""`     | Text shown when the field is empty                                |
| `disabled`    | `disabled`    | `boolean`                                                                   | `false`  | Prevents user interaction                                         |
| `required`    | `required`    | `boolean`                                                                   | `false`  | Marks the field as required for form validation                   |
| `invalid`     | `invalid`     | `boolean`                                                                   | `false`  | Marks the field as invalid without displaying a message           |
| `ariaLabel`   | `aria-label`  | `string \| null`                                                            | `null`   | Accessible name of the field, set with the `aria-label` attribute |
| `focusTarget` | —             | `HTMLInputElement`                                                          | —        | The inner element that receives the focus (read-only)             |

#### Events

| Name     | Description                                                                        |
| -------- | ---------------------------------------------------------------------------------- |
| `change` | The value was committed (re-dispatched, since the native `change` is not composed) |
| `input`  | The value changed (native event, crosses the Shadow DOM)                           |

#### CSS custom properties

| Name                 | Default                   | Description        |
| -------------------- | ------------------------- | ------------------ |
| `--hx-height-input`  | `var(--hx-height-field)`  | Height             |
| `--hx-spacing-input` | `var(--hx-spacing-field)` | Horizontal padding |
| `--hx-radius-input`  | `var(--hx-radius-field)`  | Border radius      |

#### CSS parts

| Name      | Description                 |
| --------- | --------------------------- |
| `control` | The inner `<input>` element |
