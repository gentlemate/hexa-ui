## Import

```js
import "onent-ui/input";
import "onent-ui/form-field";
```

The label, the description, the hint and the error come from [`oui-form-field`](../form-field/).

<Preview
    stack
    code={`<oui-form-field label="Email">
    <oui-input type="email" placeholder="you@example.com"></oui-input>
</oui-form-field>`}
/>

## Structure

```html
<oui-input></oui-input>
```

## Examples

### Disabled

<Preview stack code={`<oui-input aria-label="Disabled" value="John Doe" disabled></oui-input>`} />

### Invalid

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`oui-form-field`](../form-field/#error).

<Preview stack code={`<oui-input aria-label="Invalid" invalid></oui-input>`} />

### Input event

`input` fires on each keystroke, after `value` is updated.

<Preview
    stack
    code={`<oui-form-field label="Name" hint="Hello!">
    <oui-input oninput="this.parentElement.hint = this.value ? 'Hello, ' + this.value + '!' : 'Hello!'"></oui-input>
</oui-form-field>`}
/>

### Form field

In a form, [`oui-form-field`](../form-field/) adds the label, the hint and the error message.

<Preview
    stack
    code={`<oui-form-field label="Password" hint="Should not be disclosed.">
    <oui-input type="password"></oui-input>
</oui-form-field>
<oui-form-field label="Login" error="This login is already used." required>
    <oui-input value="admin"></oui-input>
</oui-form-field>`}
/>

## API

### oui-input

#### Properties

| Property      | Attribute     | Type                                                                        | Default  | Description                                                       |
| ------------- | ------------- | --------------------------------------------------------------------------- | -------- | ----------------------------------------------------------------- |
| `name`        | `name`        | `string`                                                                    | `""`     | Name submitted with the form                                      |
| `value`       | `value`       | `string`                                                                    | `""`     | Current value                                                     |
| `type`        | `type`        | `"text" \| "email" \| "password" \| "search" \| "tel" \| "url" \| "number"` | `"text"` | Type of the inner `<input>`                                       |
| `placeholder` | `placeholder` | `string`                                                                    | `""`     | Text shown when the field is empty                                |
| `disabled`    | `disabled`    | `boolean`                                                                   | `false`  | Prevents user interaction                                         |
| `required`    | `required`    | `boolean`                                                                   | `false`  | Marks the field as required for form validation                   |
| `invalid`     | `invalid`     | `boolean`                                                                   | `false`  | Marks the field as invalid without displaying a message           |
| `ariaLabel`   | `aria-label`  | `string \| null`                                                            | `null`   | Accessible name of the field, set with the `aria-label` attribute |
| `focusTarget` | —             | `HTMLInputElement`                                                          | —        | The inner element that receives the focus (read-only)             |

#### Events

| Name     | Description                                                                        |
| -------- | ---------------------------------------------------------------------------------- |
| `change` | The value was committed (re-dispatched, since the native `change` is not composed) |
| `input`  | The value changed (native event, crosses the Shadow DOM)                           |

#### CSS custom properties

| Name                  | Default                    | Description        |
| --------------------- | -------------------------- | ------------------ |
| `--oui-height-input`  | `var(--oui-height-field)`  | Height             |
| `--oui-spacing-input` | `var(--oui-spacing-field)` | Horizontal padding |
| `--oui-radius-input`  | `var(--oui-radius-field)`  | Border radius      |

#### CSS parts

| Name      | Description                 |
| --------- | --------------------------- |
| `control` | The inner `<input>` element |
