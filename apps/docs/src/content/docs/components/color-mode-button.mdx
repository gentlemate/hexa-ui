## Usage

The button toggles the `dark` class on `<html>`, which switches the `--hx-*` tokens, and stores the choice in `localStorage`. Without a stored choice, it follows `prefers-color-scheme`. Several buttons on the same page stay in sync.

## API

### hx-color-mode-button

#### Properties

| Property  | Attribute | Type                                                                | Default   | Description  |
| --------- | --------- | ------------------------------------------------------------------- | --------- | ------------ |
| `variant` | `variant` | `"primary" \| "secondary" \| "outline" \| "ghost" \| "destructive"` | `"ghost"` | Visual style |

#### Events

| Name                   | Description                                                          |
| ---------------------- | -------------------------------------------------------------------- |
| `hx-color-mode-change` | The color mode changed; `event.detail.mode` is `"light"` or `"dark"` |
