## Usage

The button toggles the `dark` class on `<html>`, which switches the `--oui-*` tokens, and stores the choice in `localStorage`. Without a stored choice, it follows `prefers-color-scheme`. Several buttons on the same page stay in sync.

## API

### oui-color-mode-button

#### Properties

| Property  | Attribute | Type                                                                | Default   | Description  |
| --------- | --------- | ------------------------------------------------------------------- | --------- | ------------ |
| `variant` | `variant` | `"primary" \| "secondary" \| "outline" \| "ghost" \| "destructive"` | `"ghost"` | Visual style |

#### Events

| Name                    | Description                                                          |
| ----------------------- | -------------------------------------------------------------------- |
| `oui-color-mode-change` | The color mode changed; `event.detail.mode` is `"light"` or `"dark"` |
