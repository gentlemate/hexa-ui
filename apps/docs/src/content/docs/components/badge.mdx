## API

### oui-badge

#### Properties

| Property        | Attribute        | Type                                                     | Default     | Description                            |
| --------------- | ---------------- | -------------------------------------------------------- | ----------- | -------------------------------------- |
| `variant`       | `variant`        | `"primary" \| "secondary" \| "outline" \| "destructive"` | `"primary"` | Visual style                           |
| `icon`          | —                | `IconNode`                                               | —           | Lucide icon, set as a JS property      |
| `iconPlacement` | `icon-placement` | `"left" \| "right"`                                      | `"left"`    | Side of the icon relative to the label |

#### Slots

| Name      | Description                     |
| --------- | ------------------------------- |
| (default) | The badge content (text, icon…) |

#### CSS custom properties

| Name                  | Default                  | Description        |
| --------------------- | ------------------------ | ------------------ |
| `--oui-height-badge`  | `1.5rem`                 | Height             |
| `--oui-spacing-badge` | `0.5rem`                 | Horizontal padding |
| `--oui-radius-badge`  | `var(--oui-radius-pill)` | Border radius      |

#### CSS parts

| Name   | Description                                      |
| ------ | ------------------------------------------------ |
| `base` | The inner wrapper                                |
| `icon` | The `oui-icon` rendered from the `icon` property |
