## Structure

```html
<oui-accordion>
    <oui-accordion-item>
        <span slot="title"></span>
    </oui-accordion-item>
</oui-accordion>
```

## Keyboard

<kbd>↑</kbd> / <kbd>↓</kbd> move the focus between the item headers, looping, and <kbd>Home</kbd> / <kbd>End</kbd> to
the first / last one. <kbd>Enter</kbd> / <kbd>Space</kbd> toggle the focused item. Disabled items are skipped.

## API

### oui-accordion

#### Properties

| Property      | Attribute     | Type                       | Default     | Description                                                               |
| ------------- | ------------- | -------------------------- | ----------- | ------------------------------------------------------------------------- |
| `type`        | `type`        | `"single" \| "multiple"`   | `"single"`  | `single` keeps one item open at a time, `multiple` lets several stay open |
| `collapsible` | `collapsible` | `boolean`                  | `false`     | In `single` mode, lets the user close the open item                       |
| `variant`     | `variant`     | `"default" \| "secondary"` | `"default"` | Visual style                                                              |
| `trigger`     | `trigger`     | `"click" \| "hover"`       | `"click"`   | Opens the items on click or on hover                                      |
| `value`       | —             | `string[]` (read-only)     | —           | Values of the open items                                                  |

#### Events

| Name                   | Description                                                     |
| ---------------------- | --------------------------------------------------------------- |
| `oui-accordion-change` | The open items changed; `event.detail.value` lists their values |

#### Slots

| Name      | Description                       |
| --------- | --------------------------------- |
| (default) | The `oui-accordion-item` elements |

#### CSS custom properties

| Name                      | Default                   | Description                                                                         |
| ------------------------- | ------------------------- | ----------------------------------------------------------------------------------- |
| `--oui-spacing-accordion` | `1rem`                    | Padding of the triggers and contents. The top padding of the contents is half of it |
| `--oui-radius-accordion`  | `var(--oui-radius-panel)` | Border radius of the `secondary` variant                                            |

#### CSS parts

| Name   | Description       |
| ------ | ----------------- |
| `base` | The items wrapper |

### oui-accordion-item

#### Properties

| Property   | Attribute  | Type                       | Default     | Description                                                      |
| ---------- | ---------- | -------------------------- | ----------- | ---------------------------------------------------------------- |
| `value`    | `value`    | `string`                   | `""`        | Identifies the item in `oui-accordion-change`                    |
| `open`     | `open`     | `boolean`                  | `false`     | Whether the item is open                                         |
| `disabled` | `disabled` | `boolean`                  | `false`     | Prevents opening or closing the item                             |
| `variant`  | `variant`  | `"default" \| "secondary"` | `"default"` | Visual style (set by the `oui-accordion`)                        |
| `trigger`  | `trigger`  | `"click" \| "hover"`       | `"click"`   | Opens the item on click or on hover (set by the `oui-accordion`) |
| `icon`     | —          | `IconNode`                 | —           | Lucide icon shown before the title, set as a JS property         |

#### Methods

| Name       | Description                                             |
| ---------- | ------------------------------------------------------- |
| `toggle()` | Opens or closes the item (fires `oui-accordion-toggle`) |

#### Events

| Name                   | Description                                                                                                                      |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `oui-accordion-toggle` | The item is about to open or close; `event.detail.open` is the new state. Cancelable: `preventDefault()` keeps the current state |

#### Slots

| Name      | Description             |
| --------- | ----------------------- |
| `title`   | The trigger label       |
| (default) | The collapsible content |

#### CSS parts

| Name        | Description                                                        |
| ----------- | ------------------------------------------------------------------ |
| `base`      | The item wrapper                                                   |
| `trigger`   | The `<button>` that toggles the item                               |
| `icon`      | The `oui-icon` rendered from the `icon` property, before the title |
| `chevron`   | The chevron                                                        |
| `content`   | The content wrapper                                                |
| `separator` | The line under the item (hidden on the last one)                   |
