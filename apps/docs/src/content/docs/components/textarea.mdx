## Import

```js
import "hexa-ui/textarea";
import "hexa-ui/form-field";
```

The label, the description, the hint and the error come from [`hx-form-field`](../form-field/).

<Preview
    stack
    code={`<hx-form-field label="Bio">
    <hx-textarea placeholder="Tell us about yourself"></hx-textarea>
</hx-form-field>`}
/>

## Structure

```html
<hx-textarea></hx-textarea>
```

## Examples

### Rows

<Preview
    stack
    code={`<hx-form-field label="Bio">
    <hx-textarea rows="8"></hx-textarea>

### Disabled

<Preview stack code={`<hx-textarea aria-label="Disabled" disabled></hx-textarea>`} />

### Invalid

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`hx-form-field`](../form-field/#error).

<Preview stack code={`<hx-textarea aria-label="Invalid" invalid></hx-textarea>`} />

### Input event

`input` fires on each keystroke, after `value` is updated.

<Preview
    stack
    code={`<hx-form-field label="Comment" hint="0 / 100 characters">
    <hx-textarea oninput="this.parentElement.hint = this.value.length + ' / 100 characters'"></hx-textarea>
</hx-form-field>`}
/>

### Form field

In a form, [`hx-form-field`](../form-field/) adds the label, the hint and the error message.

<Preview
    stack
    code={`<hx-form-field label="Comment" hint="Max 500 characters.">
    <hx-textarea></hx-textarea>
</hx-form-field>
<hx-form-field label="Message" error="This field is required." required>
    <hx-textarea></hx-textarea>
</hx-form-field>`}
/>

## API

### hx-textarea

#### Properties

| Property      | Attribute     | Type                  | Default | Description                                                       |
| ------------- | ------------- | --------------------- | ------- | ----------------------------------------------------------------- |
| `name`        | `name`        | `string`              | `""`    | Name submitted with the form                                      |
| `value`       | `value`       | `string`              | `""`    | Current value                                                     |
| `placeholder` | `placeholder` | `string`              | `""`    | Text shown when the field is empty                                |
| `rows`        | `rows`        | `number`              | `3`     | Number of visible text lines                                      |
| `disabled`    | `disabled`    | `boolean`             | `false` | Prevents user interaction                                         |
| `required`    | `required`    | `boolean`             | `false` | Marks the field as required for form validation                   |
| `invalid`     | `invalid`     | `boolean`             | `false` | Marks the field as invalid without displaying a message           |
| `ariaLabel`   | `aria-label`  | `string \| null`      | `null`  | Accessible name of the field, set with the `aria-label` attribute |
| `focusTarget` | —             | `HTMLTextAreaElement` | —       | The inner element that receives the focus (read-only)             |

#### Events

| Name     | Description                                                                        |
| -------- | ---------------------------------------------------------------------------------- |
| `change` | The value was committed (re-dispatched, since the native `change` is not composed) |
| `input`  | The value changed (native event, crosses the Shadow DOM)                           |

#### CSS custom properties

| Name                    | Default                   | Description        |
| ----------------------- | ------------------------- | ------------------ |
| `--hx-spacing-textarea` | `var(--hx-spacing-field)` | Horizontal padding |
| `--hx-radius-textarea`  | `var(--hx-radius-field)`  | Border radius      |

#### CSS parts

| Name      | Description                    |
| --------- | ------------------------------ |
| `control` | The inner `<textarea>` element |
