### Hint and error

<Preview
    stack
    code={`<hx-date-picker label="Check-in" placeholder="Pick a date" hint="Check-in from 3 pm."></hx-date-picker>

### Date style

`date-style` sets the format of the displayed date: `full`, `long`, `medium` (default) or `short`.

<Preview
    stack
    code={`<hx-date-picker label="Full" value="2026-10-25" date-style="full"></hx-date-picker>
<hx-date-picker label="Long" value="2026-10-25" date-style="long"></hx-date-picker>
<hx-date-picker label="Medium" value="2026-10-25"></hx-date-picker>
<hx-date-picker label="Short" value="2026-10-25" date-style="short"></hx-date-picker>`}
/>

### Min and max

Days outside the range are disabled in the calendar, and so are the navigation buttons that would leave it.

<Preview
    stack
    code={`<hx-date-picker label="Date" placeholder="Pick a date" min="2026-01-01" max="2026-12-31"></hx-date-picker>`}
/>

### Month and year selects

`month-select` and `year-select` turn the month and the year of the calendar heading into selects, independently. Without `min` / `max`, the years go from 100 years before to 100 years after today.

<Preview
    stack
    code={`<hx-date-picker label="Month select" placeholder="Pick a date" month-select></hx-date-picker>
<hx-date-picker label="Year select" placeholder="Pick a date" year-select></hx-date-picker>
<hx-date-picker label="Both" placeholder="Pick a date" month-select year-select></hx-date-picker>`}
/>

### Locale

The displayed date, the month and weekday names, and the first day of the week follow `locale`, or the closest `lang` attribute.

<Preview
    stack
    code={`<hx-date-picker label="French" locale="fr-FR" value="2026-10-25"></hx-date-picker>
<hx-date-picker label="American" locale="en-US" value="2026-10-25"></hx-date-picker>
<hx-date-picker label="Japanese" locale="ja-JP" value="2026-10-25"></hx-date-picker>`}
/>

### Disabled

<Preview stack code={`<hx-date-picker label="Date" value="2026-10-25" disabled></hx-date-picker>`} />

### Change event

`change` fires when the user selects a day, after `value` is updated.

<Preview
    stack
    code={`<hx-date-picker
    label="Date"
    value="2026-10-25"
    hint="Sunday, 25 October 2026"
    onchange="this.hint = new Date(this.value + 'T00:00').toLocaleDateString('en-GB', { dateStyle: 'full' })"
></hx-date-picker>`}
/>

### Form

`name` submits the date as a `YYYY-MM-DD` field.

<Preview
    stack
    code={`<form onsubmit="event.preventDefault(); this.querySelector('p').textContent = new URLSearchParams(new FormData(this))">
    <hx-date-picker label="Date" name="date" value="2026-10-25"></hx-date-picker>
    <hx-button type="submit" class="mt-3">Submit</hx-button>
    <p class="mt-2 text-sm"></p>
</form>`}
/>

## Behavior

`value`, `min` and `max` are always in the `YYYY-MM-DD` format (like `<input type="date">`), whatever the `locale`: it only changes how the date is displayed. Convert `value` with `new Date(value + "T00:00")` to get a local date, since `new Date(value)` reads it as UTC.

## Keyboard

<kbd>↓</kbd> / <kbd>↑</kbd> on the trigger open the calendar, which focuses the selected day (or today). The calendar
keys then apply (see [Calendar](../calendar/#keyboard)); <kbd>Enter</kbd> / <kbd>Space</kbd> select the focused day and
close the calendar. <kbd>Escape</kbd>, or moving the focus out of the calendar, closes it.

## API

### hx-date-picker

#### Properties

| Property      | Attribute      | Type                                                                                                                                                                 | Default          | Description                                                                                  |
| ------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------------- |
| `name`        | `name`         | `string`                                                                                                                                                             | `""`             | Name submitted with the form                                                                 |
| `value`       | `value`        | `string`                                                                                                                                                             | `""`             | Selected date, as `YYYY-MM-DD`                                                               |
| `label`       | `label`        | `string`                                                                                                                                                             | `""`             | Label displayed above the field                                                              |
| `placeholder` | `placeholder`  | `string`                                                                                                                                                             | `""`             | Text shown when no date is selected                                                          |
| `hint`        | `hint`         | `string`                                                                                                                                                             | `""`             | Help text under the field, replaced by `error` when set                                      |
| `error`       | `error`        | `string`                                                                                                                                                             | `""`             | Error message under the field; also marks the field as invalid                               |
| `min`         | `min`          | `string`                                                                                                                                                             | `""`             | Earliest selectable date, as `YYYY-MM-DD`                                                    |
| `max`         | `max`          | `string`                                                                                                                                                             | `""`             | Latest selectable date, as `YYYY-MM-DD`                                                      |
| `locale`      | `locale`       | `string`                                                                                                                                                             | `""`             | Language of the displayed date and of the calendar; defaults to the closest `lang` attribute |
| `dateStyle`   | `date-style`   | `"full" \| "long" \| "medium" \| "short"`                                                                                                                            | `"medium"`       | Format of the displayed date                                                                 |
| `monthSelect` | `month-select` | `boolean`                                                                                                                                                            | `false`          | Shows the month of the calendar as a select                                                  |
| `yearSelect`  | `year-select`  | `boolean`                                                                                                                                                            | `false`          | Shows the year of the calendar as a select                                                   |
| `placement`   | `placement`    | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom-start"` | Position of the calendar relative to the trigger                                             |
| `distance`    | `distance`     | `number`                                                                                                                                                             | `4`              | Gap in pixels between the trigger and the calendar                                           |
| `disabled`    | `disabled`     | `boolean`                                                                                                                                                            | `false`          | Prevents user interaction                                                                    |
| `required`    | `required`     | `boolean`                                                                                                                                                            | `false`          | Adds an asterisk to the label and marks the field as required for assistive technologies     |
| `focusTarget` | —              | `HTMLButtonElement`                                                                                                                                                  | —                | The inner element that receives the focus (read-only)                                        |
| `open`        | `open`         | `boolean`                                                                                                                                                            | `false`          | Whether it is open. Setting it directly skips `hx-show` / `hx-hide`                          |

#### Methods

| Name     | Description                 |
| -------- | --------------------------- |
| `show()` | Opens it (fires `hx-show`)  |
| `hide()` | Closes it (fires `hx-hide`) |

#### Events

| Name            | Description                                            |
| --------------- | ------------------------------------------------------ |
| `input`         | The user selected another date                         |
| `change`        | The user selected another date                         |
| `hx-show`       | The calendar is about to open. Cancelable              |
| `hx-after-show` | The calendar is open and its enter animation finished  |
| `hx-hide`       | The calendar is about to close. Cancelable             |
| `hx-after-hide` | The calendar is closed and its exit animation finished |

#### CSS parts

| Name       | Description                           |
| ---------- | ------------------------------------- |
| `trigger`  | The button showing the selected date  |
| `value`    | The selected date, or the placeholder |
| `icon`     | The calendar icon of the trigger      |
| `popup`    | The panel holding the calendar        |
| `calendar` | The `hx-calendar`                     |
