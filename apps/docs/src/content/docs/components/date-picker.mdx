## Import

```js
import "onent-ui/date-picker";
import "onent-ui/form-field";
```

The label, the description, the hint and the error come from [`oui-form-field`](../form-field/).

<Preview
    stack
    code={`<oui-form-field label="Birthday">
    <oui-date-picker placeholder="Pick a date"></oui-date-picker>
</oui-form-field>`}
/>

## Structure

```html
<oui-date-picker></oui-date-picker>
```

## Examples

### Date style

`date-style` sets the format of the displayed date: `full`, `long`, `medium` (default) or `short`.

<Preview
    stack
    code={`<oui-form-field label="Full">
    <oui-date-picker value="2026-10-25" date-style="full"></oui-date-picker>
</oui-form-field>
<oui-form-field label="Long">
    <oui-date-picker value="2026-10-25" date-style="long"></oui-date-picker>
</oui-form-field>
<oui-form-field label="Medium">
    <oui-date-picker value="2026-10-25"></oui-date-picker>
</oui-form-field>
<oui-form-field label="Short">
    <oui-date-picker value="2026-10-25" date-style="short"></oui-date-picker>
</oui-form-field>`}
/>

### Min and max

Days outside the range are disabled in the calendar, and so are the navigation buttons that would leave it.

<Preview
    stack
    code={`<oui-form-field label="Date">
    <oui-date-picker placeholder="Pick a date" min="2026-01-01" max="2026-12-31"></oui-date-picker>
</oui-form-field>`}
/>

### Month and year selects

`month-select` and `year-select` turn the month and the year of the calendar heading into selects, independently. Without `min` / `max`, the years go from 100 years before to 100 years after today.

<Preview
    stack
    code={`<oui-form-field label="Month select">
    <oui-date-picker placeholder="Pick a date" month-select></oui-date-picker>
</oui-form-field>
<oui-form-field label="Year select">
    <oui-date-picker placeholder="Pick a date" year-select></oui-date-picker>
</oui-form-field>
<oui-form-field label="Both">
    <oui-date-picker placeholder="Pick a date" month-select year-select></oui-date-picker>
</oui-form-field>`}
/>

<Preview stack code={`<oui-date-picker aria-label="Disabled" value="2026-10-25" disabled></oui-date-picker>`} />

### Invalid

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`oui-form-field`](../form-field/#error).

<Preview stack code={`<oui-date-picker aria-label="Invalid" placeholder="Pick a date" invalid></oui-date-picker>`} />

### Change event

`change` fires when the user selects a day, after `value` is updated.

<Preview
    stack
    code={`<oui-form-field label="Date" hint="Sunday, 25 October 2026">
    <oui-date-picker
        value="2026-10-25"
        onchange="this.parentElement.hint = new Date(this.value + 'T00:00').toLocaleDateString('en-GB', { dateStyle: 'full' })"
    ></oui-date-picker>
</oui-form-field>`}
/>

### Form

`name` submits the date as a `YYYY-MM-DD` field.

<Preview
    stack
    code={`<form onsubmit="event.preventDefault(); this.querySelector('p').textContent = new URLSearchParams(new FormData(this))">
    <oui-form-field label="Date">
        <oui-date-picker name="date" value="2026-10-25"></oui-date-picker>
    </oui-form-field>
    <oui-button type="submit" class="mt-3">Submit</oui-button>
    <p class="mt-2 text-sm"></p>
</form>`}
/>

### Form field

In a form, [`oui-form-field`](../form-field/) adds the label, the hint and the error message.

<Preview
    stack
    code={`<oui-form-field label="Check-in" hint="Check-in from 3 pm.">
    <oui-date-picker placeholder="Pick a date"></oui-date-picker>
</oui-form-field>
<oui-form-field label="Check-out" error="Your stay must be at least 2 nights.">
    <oui-date-picker value="2025-10-25"></oui-date-picker>
</oui-form-field>`}
/>

## Behavior

`value`, `min` and `max` are always in the `YYYY-MM-DD` format (like `<input type="date">`), whatever the `locale`: it only changes how the date is displayed. Convert `value` with `new Date(value + "T00:00")` to get a local date, since `new Date(value)` reads it as UTC.

## Keyboard

<kbd>↓</kbd> / <kbd>↑</kbd> on the trigger open the calendar, which focuses the selected day (or today). The calendar
keys then apply (see [Calendar](../calendar/#keyboard)); <kbd>Enter</kbd> / <kbd>Space</kbd> select the focused day and
close the calendar. <kbd>Escape</kbd>, or moving the focus out of the calendar, closes it.

## API

### oui-date-picker

#### Properties

| Property      | Attribute      | Type                                                                                                                                                                 | Default          | Description                                                                                  |
| ------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------------- |
| `name`        | `name`         | `string`                                                                                                                                                             | `""`             | Name submitted with the form                                                                 |
| `value`       | `value`        | `string`                                                                                                                                                             | `""`             | Selected date, as `YYYY-MM-DD`                                                               |
| `min`         | `min`          | `string`                                                                                                                                                             | `""`             | Earliest selectable date, as `YYYY-MM-DD`                                                    |
| `max`         | `max`          | `string`                                                                                                                                                             | `""`             | Latest selectable date, as `YYYY-MM-DD`                                                      |
| `locale`      | `locale`       | `string`                                                                                                                                                             | `""`             | Language of the displayed date and of the calendar; defaults to the closest `lang` attribute |
| `dateStyle`   | `date-style`   | `"full" \| "long" \| "medium" \| "short"`                                                                                                                            | `"medium"`       | Format of the displayed date                                                                 |
| `monthSelect` | `month-select` | `boolean`                                                                                                                                                            | `false`          | Shows the month of the calendar as a select                                                  |
| `yearSelect`  | `year-select`  | `boolean`                                                                                                                                                            | `false`          | Shows the year of the calendar as a select                                                   |
| `placement`   | `placement`    | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom-start"` | Position of the calendar relative to the trigger                                             |
| `distance`    | `distance`     | `number`                                                                                                                                                             | `4`              | Gap in pixels between the trigger and the calendar                                           |
| `placeholder` | `placeholder`  | `string`                                                                                                                                                             | `""`             | Text shown when nothing is selected                                                          |
| `disabled`    | `disabled`     | `boolean`                                                                                                                                                            | `false`          | Prevents user interaction                                                                    |
| `required`    | `required`     | `boolean`                                                                                                                                                            | `false`          | Marks the field as required for form validation                                              |
| `invalid`     | `invalid`      | `boolean`                                                                                                                                                            | `false`          | Marks the field as invalid without displaying a message                                      |
| `ariaLabel`   | `aria-label`   | `string \| null`                                                                                                                                                     | `null`           | Accessible name of the field, set with the `aria-label` attribute                            |
| `focusTarget` | —              | `HTMLButtonElement`                                                                                                                                                  | —                | The inner element that receives the focus (read-only)                                        |
| `open`        | `open`         | `boolean`                                                                                                                                                            | `false`          | Whether it is open. Setting it directly skips `oui-show` / `oui-hide`                        |

#### Methods

| Name     | Description                  |
| -------- | ---------------------------- |
| `show()` | Opens it (fires `oui-show`)  |
| `hide()` | Closes it (fires `oui-hide`) |

#### Events

| Name             | Description                                            |
| ---------------- | ------------------------------------------------------ |
| `input`          | The user selected another date                         |
| `change`         | The user selected another date                         |
| `oui-show`       | The calendar is about to open. Cancelable              |
| `oui-after-show` | The calendar is open and its enter animation finished  |
| `oui-hide`       | The calendar is about to close. Cancelable             |
| `oui-after-hide` | The calendar is closed and its exit animation finished |

#### CSS custom properties

| Name                        | Default                    | Description                                                                 |
| --------------------------- | -------------------------- | --------------------------------------------------------------------------- |
| `--oui-height-date-picker`  | `var(--oui-height-field)`  | Height of the trigger                                                       |
| `--oui-spacing-date-picker` | `var(--oui-spacing-field)` | Horizontal padding of the trigger                                           |
| `--oui-radius-date-picker`  | `var(--oui-radius-field)`  | Border radius of the trigger                                                |
| `--oui-spacing-calendar`    | `var(--oui-spacing-popup)` | Padding around the calendar                                                 |
| `--oui-size-calendar-day`   | `2.25rem`                  | Width and height of the day cells, and height of the month and year selects |

#### CSS parts

| Name       | Description                           |
| ---------- | ------------------------------------- |
| `trigger`  | The button showing the selected date  |
| `value`    | The selected date, or the placeholder |
| `icon`     | The calendar icon of the trigger      |
| `popup`    | The panel holding the calendar        |
| `calendar` | The `oui-calendar`                    |
