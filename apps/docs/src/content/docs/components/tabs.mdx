## Keyboard

<kbd>←</kbd> / <kbd>→</kbd> (<kbd>↑</kbd> / <kbd>↓</kbd> with `direction="vertical"`) move to the previous / next tab,
looping, and <kbd>Home</kbd> / <kbd>End</kbd> to the first / last one. The focused tab is selected right away. Disabled
tabs are skipped. Only the selected tab is in the tab order.

## API

### oui-tabs

#### Properties

| Property    | Attribute   | Type                                   | Default        | Description                                                     |
| ----------- | ----------- | -------------------------------------- | -------------- | --------------------------------------------------------------- |
| `value`     | `value`     | `string`                               | `""`           | Value of the selected tab                                       |
| `variant`   | `variant`   | `"default" \| "secondary" \| "button"` | `"default"`    | Visual style                                                    |
| `direction` | `direction` | `"horizontal" \| "vertical"`           | `"horizontal"` | Tab list above (`horizontal`) or beside (`vertical`) the panels |

#### Events

| Name             | Description                                                 |
| ---------------- | ----------------------------------------------------------- |
| `oui-tab-change` | The selected tab changed; `event.detail.value` is its value |

#### Slots

| Name      | Description                                                                         |
| --------- | ----------------------------------------------------------------------------------- |
| (default) | The `oui-tab` and `oui-tab-panel` elements (tabs move to the tab list on their own) |

#### CSS custom properties

| Name                 | Default                                  | Description                    |
| -------------------- | ---------------------------------------- | ------------------------------ |
| `--oui-height-tabs`  | `var(--oui-height-control)`              | Height of the tab list         |
| `--oui-spacing-tabs` | `0.25rem`                                | Padding of the tab list        |
| `--oui-spacing-tab`  | `var(--oui-spacing-control)`             | Horizontal padding of each tab |
| `--oui-radius-tabs`  | `calc(var(--oui-radius-tab) + 0.125rem)` | Border radius of the tab list  |
| `--oui-radius-tab`   | `var(--oui-radius-control)`              | Border radius of each tab      |

#### CSS parts

| Name   | Description                                                |
| ------ | ---------------------------------------------------------- |
| `nav`  | The tab list                                               |
| `body` | The panels wrapper (not displayed without `oui-tab-panel`) |

### oui-tab

#### Properties

| Property        | Attribute        | Type                                   | Default        | Description                                                 |
| --------------- | ---------------- | -------------------------------------- | -------------- | ----------------------------------------------------------- |
| `value`         | `value`          | `string`                               | `""`           | Matches the `value` of its `oui-tab-panel`                  |
| `selected`      | `selected`       | `boolean`                              | `false`        | Whether the tab is selected (set by the `oui-tabs`)         |
| `disabled`      | `disabled`       | `boolean`                              | `false`        | Prevents selecting the tab                                  |
| `variant`       | `variant`        | `"default" \| "secondary" \| "button"` | `"default"`    | Visual style (set by the `oui-tabs`)                        |
| `direction`     | `direction`      | `"horizontal" \| "vertical"`           | `"horizontal"` | Tab list above or beside the panels (set by the `oui-tabs`) |
| `icon`          | —                | `IconNode`                             | —              | Lucide icon, set as a JS property                           |
| `iconPlacement` | `icon-placement` | `"left" \| "right"`                    | `"left"`       | Side of the icon relative to the label                      |

#### Slots

| Name      | Description                 |
| --------- | --------------------------- |
| (default) | The tab label (text, icon…) |

#### CSS parts

| Name   | Description                                      |
| ------ | ------------------------------------------------ |
| `base` | The tab wrapper                                  |
| `icon` | The `oui-icon` rendered from the `icon` property |

### oui-tab-panel

#### Properties

| Property | Attribute | Type     | Default | Description                          |
| -------- | --------- | -------- | ------- | ------------------------------------ |
| `value`  | `value`   | `string` | `""`    | Matches the `value` of its `oui-tab` |

#### Slots

| Name      | Description       |
| --------- | ----------------- |
| (default) | The panel content |
