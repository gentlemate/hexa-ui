## Keyboard

<kbd>←</kbd> / <kbd>→</kbd> (<kbd>↑</kbd> / <kbd>↓</kbd> with `direction="vertical"`) move to the previous / next tab,
looping, and <kbd>Home</kbd> / <kbd>End</kbd> to the first / last one. The focused tab is selected right away. Disabled
tabs are skipped. Only the selected tab is in the tab order.

## API

### hx-tabs

#### Properties

| Property    | Attribute   | Type                         | Default        | Description                                                     |
| ----------- | ----------- | ---------------------------- | -------------- | --------------------------------------------------------------- |
| `value`     | `value`     | `string`                     | `""`           | Value of the selected tab                                       |
| `variant`   | `variant`   | `"default" \| "secondary"`   | `"default"`    | Visual style                                                    |
| `direction` | `direction` | `"horizontal" \| "vertical"` | `"horizontal"` | Tab list above (`horizontal`) or beside (`vertical`) the panels |

#### Events

| Name            | Description                                                 |
| --------------- | ----------------------------------------------------------- |
| `hx-tab-change` | The selected tab changed; `event.detail.value` is its value |

#### Slots

| Name      | Description                                                                       |
| --------- | --------------------------------------------------------------------------------- |
| (default) | The `hx-tab` and `hx-tab-panel` elements (tabs move to the tab list on their own) |

#### CSS parts

| Name   | Description        |
| ------ | ------------------ |
| `nav`  | The tab list       |
| `body` | The panels wrapper |

### hx-tab

| Property        | Attribute        | Type                | Default  | Description                                            |
| --------------- | ---------------- | ------------------- | -------- | ------------------------------------------------------ |
| `value`         | `value`          | `string`            | `""`     | Matches the `value` of its `hx-tab-panel`              |
| `selected`      | `selected`       | `boolean`           | `false`  | Whether the tab is selected (managed by the `hx-tabs`) |
| `disabled`      | `disabled`       | `boolean`           | `false`  | Prevents selecting the tab                             |
| `icon`          | —                | `IconNode`          | —        | Lucide icon, set as a JS property                      |
| `iconPlacement` | `icon-placement` | `"left" \| "right"` | `"left"` | Side of the icon relative to the label                 |

`variant` and `direction` are set by the `hx-tabs`. CSS parts: `base` (the tab wrapper), `icon` (the `hx-icon` rendered from the `icon` property).

### hx-tab-panel

| Property | Attribute | Type     | Default | Description                         |
| -------- | --------- | -------- | ------- | ----------------------------------- |
| `value`  | `value`   | `string` | `""`    | Matches the `value` of its `hx-tab` |
