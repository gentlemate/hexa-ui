## Import

```js
import "onent-ui/checkbox";
```

<Preview code={`<oui-checkbox checked>Remember me</oui-checkbox>`} />

## Structure

```html
<oui-checkbox></oui-checkbox>
```

## Examples

### States

`indeterminate` shows a dash. It is cleared when the user toggles the checkbox.

<Preview
    code={`<div class="flex flex-col gap-3">
    <oui-checkbox>Default</oui-checkbox>
    <oui-checkbox indeterminate>Indeterminate</oui-checkbox>
    <oui-checkbox checked>Checked</oui-checkbox>
</div>`}
/>

### Disabled

<Preview
    code={`<oui-checkbox disabled>Disabled</oui-checkbox>
<oui-checkbox checked disabled>Checked and disabled</oui-checkbox>`}
/>

### Invalid

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`oui-form-field`](../form-field/#error).

<Preview code={`<oui-checkbox invalid>Invalid</oui-checkbox>`} />

### Change event

`change` fires each time the checkbox is toggled.

<Preview code={`<oui-checkbox onchange="this.textContent = this.checked ? 'On' : 'Off'">Off</oui-checkbox>`} />

## Keyboard

<kbd>Space</kbd> toggles the checkbox.

## API

### oui-checkbox

#### Properties

| Property        | Attribute       | Type      | Default | Description                                                              |
| --------------- | --------------- | --------- | ------- | ------------------------------------------------------------------------ |
| `indeterminate` | `indeterminate` | `boolean` | `false` | Shows a dash instead of the check mark; cleared when the user toggles it |
| `value`         | `value`         | `string`  | `"on"`  | Value submitted with the form when checked                               |
| `checked`       | `checked`       | `boolean` | `false` | Whether the checkbox is checked (not reflected as an attribute)          |
| `name`          | `name`          | `string`  | `""`    | Name submitted with the form                                             |
| `disabled`      | `disabled`      | `boolean` | `false` | Prevents user interaction                                                |
| `required`      | `required`      | `boolean` | `false` | Marks the field as required for form validation                          |
| `invalid`       | `invalid`       | `boolean` | `false` | Marks the field as invalid without displaying a message                  |

#### Events

| Name     | Description               |
| -------- | ------------------------- |
| `input`  | The checked state changed |
| `change` | The checked state changed |

#### Slots

| Name      | Description        |
| --------- | ------------------ |
| (default) | The checkbox label |

#### CSS custom properties

| Name                    | Default    | Description                 |
| ----------------------- | ---------- | --------------------------- |
| `--oui-size-checkbox`   | `1.25rem`  | Width and height of the box |
| `--oui-radius-checkbox` | `0.375rem` | Border radius of the box    |

#### CSS parts

| Name      | Description       |
| --------- | ----------------- |
| `control` | The box           |
| `label`   | The label wrapper |

#### CSS states

| Name      | Description             |
| --------- | ----------------------- |
| `checked` | The checkbox is checked |
