## API

### oui-separator

#### Properties

| Property    | Attribute   | Type                         | Default        | Description             |
| ----------- | ----------- | ---------------------------- | -------------- | ----------------------- |
| `direction` | `direction` | `"horizontal" \| "vertical"` | `"horizontal"` | Orientation of the line |

#### CSS custom properties

| Name                      | Default | Description                     |
| ------------------------- | ------- | ------------------------------- |
| `--oui-spacing-separator` | `1rem`  | Space on both sides of the line |

#### CSS parts

| Name   | Description                           |
| ------ | ------------------------------------- |
| `line` | The line, with its spacing as margins |
