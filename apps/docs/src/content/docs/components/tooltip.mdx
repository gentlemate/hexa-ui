### Distance

`distance` sets the gap in pixels between the trigger and the tooltip (`8` by default).

<Preview
    code={`<hx-tooltip content="16px away" distance="16">

</hx-tooltip>`}
/>

### Open delay

`open-delay` sets the delay in milliseconds before the tooltip opens on hover (`300` by default).

## Usage

The tooltip opens on hover (after `open-delay`) and on keyboard focus. It closes on pointer leave, blur, click and <kbd>Escape</kbd>. Its text is exposed as the trigger's `aria-description`.

## API

### hx-tooltip

#### Properties

| Property       | Attribute       | Type                                                                                                                                                                 | Default | Description                                                         |
| -------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- | ------------------------------------------------------------------- |
| `content`      | `content`       | `string`                                                                                                                                                             | `""`    | Tooltip text; use the `content` slot for rich content               |
| `placement`    | `placement`     | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"top"` | Position of the tooltip relative to the trigger                     |
| `distance`     | `distance`      | `number`                                                                                                                                                             | `8`     | Gap in pixels between the trigger and the popup                     |
| `openDelay`    | `open-delay`    | `number`                                                                                                                                                             | `300`   | Delay in milliseconds before opening on hover                       |
| `closeDelay`   | `close-delay`   | `number`                                                                                                                                                             | `100`   | Delay in milliseconds before closing on pointer leave               |
| `disabled`     | `disabled`      | `boolean`                                                                                                                                                            | `false` | Prevents the tooltip from opening                                   |
| `withoutArrow` | `without-arrow` | `boolean`                                                                                                                                                            | `false` | Hides the arrow                                                     |
| `open`         | `open`          | `boolean`                                                                                                                                                            | `false` | Whether it is open. Setting it directly skips `hx-show` / `hx-hide` |

#### Methods

| Name     | Description                 |
| -------- | --------------------------- |
| `show()` | Opens it (fires `hx-show`)  |
| `hide()` | Closes it (fires `hx-hide`) |

#### Events

| Name            | Description                                           |
| --------------- | ----------------------------------------------------- |
| `hx-show`       | The tooltip is about to open. Cancelable              |
| `hx-after-show` | The tooltip is open and its enter animation finished  |
| `hx-hide`       | The tooltip is about to close. Cancelable             |
| `hx-after-hide` | The tooltip is closed and its exit animation finished |

#### Slots

| Name      | Description                                             |
| --------- | ------------------------------------------------------- |
| (default) | The trigger (the first element is the anchor)           |
| `content` | Rich tooltip content, instead of the `content` property |

#### CSS parts

| Name    | Description                                                           |
| ------- | --------------------------------------------------------------------- |
| `popup` | The tooltip bubble                                                    |
| `arrow` | The arrow pointing to the trigger (not rendered with `without-arrow`) |
