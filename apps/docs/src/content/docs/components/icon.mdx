### Label

Without `label`, the icon is decorative and hidden from assistive technologies. With `label`, it is announced.

<Preview code={`<oui-icon data-icon="Trash2" label="Delete"></oui-icon>`} />

## API

### oui-icon

#### Properties

| Property      | Attribute      | Type       | Default | Description                                         |
| ------------- | -------------- | ---------- | ------- | --------------------------------------------------- |
| `icon`        | —              | `IconNode` | —       | Lucide icon to render, set as a JS property         |
| `size`        | `size`         | `number`   | `16`    | Width and height in pixels                          |
| `strokeWidth` | `stroke-width` | `number`   | `2`     | Stroke width of the paths                           |
| `label`       | `label`        | `string`   | `""`    | Accessible name; without it, the icon is decorative |

#### CSS parts

| Name  | Description               |
| ----- | ------------------------- |
| `svg` | The inner `<svg>` element |
