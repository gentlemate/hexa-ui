### Format

`format-options` takes the options of [`Intl.NumberFormat`](https://developer.mozilla.org/docs/Web/JavaScript/Reference/Global_Objects/Intl/NumberFormat/NumberFormat#options), as JSON. With `"style": "percent"`, `value` is a fraction (`0.25` is displayed `25%`), so `step` is usually `0.01`.

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`hx-form-field`](../form-field/#error).

### Input event

`input` fires once the value is committed, after `value` is updated.

/>

/>

## Behavior

`value` is a `number`, or `undefined` while the field is empty, whatever the `locale` and `format-options`: they only change how the number is displayed and read. The form receives `value` as a plain number string (`1234.5`).

The text is read and committed when the field loses the focus or on <kbd>Enter</kbd>: it is rounded to the displayed fraction digits and clamped between `min` and `max`, then `input` / `change` fire. A text that is not a number is discarded. Each step is committed right away, and an empty field starts from `0`, clamped between `min` and `max`.

## Keyboard

The field is a single tab stop: the buttons are not focusable. <kbd>↑</kbd> / <kbd>↓</kbd> add / remove `step`, <kbd>Home</kbd> / <kbd>End</kbd> go to `min` / `max` and <kbd>Enter</kbd> commits the text. While the field has the focus, the mouse wheel adds / removes `step` too.

## API

### hx-number-field

#### Properties

| Property        | Attribute        | Type                       | Default     | Description                                                                                       |
| --------------- | ---------------- | -------------------------- | ----------- | ------------------------------------------------------------------------------------------------- |
| `name`          | `name`           | `string`                   | `""`        | Name submitted with the form                                                                      |
| `value`         | `value`          | `number`                   | —           | Current number; `undefined` while the field is empty                                              |
| `min`           | `min`            | `number`                   | —           | Smallest allowed value                                                                            |
| `max`           | `max`            | `number`                   | —           | Largest allowed value                                                                             |
| `step`          | `step`           | `number`                   | `1`         | Amount added or removed by the buttons, the arrow keys and the mouse wheel                        |
| `placeholder`   | `placeholder`    | `string`                   | `""`        | Text shown when the field is empty                                                                |
| `locale`        | `locale`         | `string`                   | `""`        | Separators and digits of the number; defaults to the closest `lang` attribute                     |
| `formatOptions` | `format-options` | `Intl.NumberFormatOptions` | `{}`        | `Intl.NumberFormat` options (currency, percent, unit, fraction digits…), as JSON in the attribute |
| `variant`       | `variant`        | `"default" \| "secondary"` | `"default"` | `default` puts − and + on each side, `secondary` stacks two chevrons on the right                 |
| `disabled`      | `disabled`       | `boolean`                  | `false`     | Prevents user interaction                                                                         |
| `required`      | `required`       | `boolean`                  | `false`     | Marks the field as required for form validation                                                   |
| `invalid`       | `invalid`        | `boolean`                  | `false`     | Marks the field as invalid without displaying a message                                           |
| `ariaLabel`     | `aria-label`     | `string \| null`           | `null`      | Accessible name of the field, set with the `aria-label` attribute                                 |
| `focusTarget`   | —                | `HTMLInputElement`         | —           | The inner element that receives the focus (read-only)                                             |

#### Events

| Name     | Description       |
| -------- | ----------------- |
| `input`  | The value changed |
| `change` | The value changed |

#### CSS custom properties

| Name                        | Default                   | Description        |
| --------------------------- | ------------------------- | ------------------ |
| `--hx-height-number-field`  | `var(--hx-height-field)`  | Height             |
| `--hx-spacing-number-field` | `var(--hx-spacing-field)` | Horizontal padding |
| `--hx-radius-number-field`  | `var(--hx-radius-field)`  | Border radius      |

#### CSS parts

| Name        | Description                    |
| ----------- | ------------------------------ |
| `control`   | The inner `<input>` element    |
| `decrement` | The button that removes `step` |
| `increment` | The button that adds `step`    |
