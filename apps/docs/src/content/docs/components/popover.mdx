### Distance

`distance` sets the gap in pixels between the trigger and the popover (`8` by default).

<Preview
    code={`<oui-popover distance="16">
    <oui-button slot="trigger">Distance</oui-button>
    <p class="text-sm">16px away</p>
</oui-popover>`}
/>

### Hover

`trigger="hover"` opens the popover when the pointer rests on the trigger, and closes it when the pointer leaves both the trigger and the popover.

<Preview
    code={`<oui-popover trigger="hover">
    <oui-button slot="trigger">Hover me</oui-button>
    <p class="w-64 text-sm">Opens on hover, closes when the pointer leaves.</p>
</oui-popover>`}
/>

### Open and close delays

`open-delay` sets the delay in milliseconds before the popover opens on hover (`300` by default), and `close-delay` the delay before it closes once the pointer has left (`100` by default).

<Preview
    code={`<oui-popover trigger="hover" open-delay="0" close-delay="0">
    <oui-button slot="trigger">No delay</oui-button>
    <p class="text-sm">No delay</p>
</oui-popover>`}
/>

## Usage

The popover opens on click of the trigger and moves the focus to its panel. It closes on a second click, on a click outside, on <kbd>Escape</kbd>, or when the focus leaves it, then gives the focus back to the trigger. With `trigger="hover"`, it opens on hover without moving the focus; a click or <kbd>Enter</kbd> on the trigger still opens it, for keyboard and touch users.

## API

### oui-popover

#### Properties

| Property       | Attribute       | Type                                                                                                                                                                 | Default    | Description                                                                    |
| -------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ------------------------------------------------------------------------------ |
| `placement`    | `placement`     | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom"` | Position of the popover relative to the trigger                                |
| `distance`     | `distance`      | `number`                                                                                                                                                             | `8`        | Gap in pixels between the trigger and the popup                                |
| `trigger`      | `trigger`       | `"click" \| "hover"`                                                                                                                                                 | `"click"`  | Opens the popover on click or on hover                                         |
| `openDelay`    | `open-delay`    | `number`                                                                                                                                                             | `300`      | Delay in milliseconds before opening on hover (with `trigger="hover"`)         |
| `closeDelay`   | `close-delay`   | `number`                                                                                                                                                             | `100`      | Delay in milliseconds before closing on pointer leave (with `trigger="hover"`) |
| `withoutArrow` | `without-arrow` | `boolean`                                                                                                                                                            | `false`    | Hides the arrow                                                                |
| `open`         | `open`          | `boolean`                                                                                                                                                            | `false`    | Whether it is open. Setting it directly skips `oui-show` / `oui-hide`          |

#### Methods

| Name     | Description                  |
| -------- | ---------------------------- |
| `show()` | Opens it (fires `oui-show`)  |
| `hide()` | Closes it (fires `oui-hide`) |

#### Events

| Name             | Description                                           |
| ---------------- | ----------------------------------------------------- |
| `oui-show`       | The popover is about to open. Cancelable              |
| `oui-after-show` | The popover is open and its enter animation finished  |
| `oui-hide`       | The popover is about to close. Cancelable             |
| `oui-after-hide` | The popover is closed and its exit animation finished |

#### Slots

| Name      | Description                                               |
| --------- | --------------------------------------------------------- |
| `trigger` | The element that opens the popover (e.g. an `oui-button`) |
| (default) | The popover content                                       |

#### CSS custom properties

| Name                    | Default                   | Description   |
| ----------------------- | ------------------------- | ------------- |
| `--oui-spacing-popover` | `1.25rem`                 | Padding       |
| `--oui-radius-popover`  | `var(--oui-radius-popup)` | Border radius |

#### CSS parts

| Name    | Description                                                           |
| ------- | --------------------------------------------------------------------- |
| `popup` | The popover panel                                                     |
| `arrow` | The arrow pointing to the trigger (not rendered with `without-arrow`) |
