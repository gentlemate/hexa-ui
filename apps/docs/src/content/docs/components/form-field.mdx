## Structure

```html
<hx-form-field>
    <hx-input></hx-input>
</hx-form-field>
```

The first form control inside the field receives `name`, `required` and its accessible name. It can be wrapped in other elements.

### Rich content

The `label`, `description`, `help`, `hint` and `error` slots replace the properties of the same name. The `error` slot is displayed while `error` is set.

<Preview
    stack
    code={`<hx-form-field error="invalid">
    <span slot="label">Password <hx-badge variant="destructive">Weak</hx-badge></span>
    <span slot="error">Too short, see the <a href="#rich-content" class="underline">password rules</a>.</span>
    <hx-input type="password" value="1234"></hx-input>
</hx-form-field>`}
/>

### Checkbox and switch

Without `label`, the field only adds its messages to the control.

<Preview
    stack
    code={`<hx-form-field error="You must accept the terms.">
    <hx-checkbox>I accept the terms</hx-checkbox>
</hx-form-field>

    <hx-switch>Enabled</hx-switch>
</hx-form-field>`}
/>

### Slider

The formatted value of an `hx-slider` is displayed at the end of the label row.

<Preview
    stack
    code={`<hx-form-field label="Volume" help="Output level">
    <hx-slider value="50"></hx-slider>
</hx-form-field>`}
/>

### Eager validation

Inside an [`hx-form`](../form/), validation on `input` waits for the first blur of the field. `eager-validation` removes this wait.

```html
<hx-form-field name="login" label="Login" eager-validation>
    <hx-input></hx-input>
</hx-form-field>
```

## Usage

A click on the label focuses the control. The label, the description, the hint and the error are also exposed to assistive technologies through the control.

A control does not need a field. Without one, `aria-label` or an [`hx-label`](../label/) gives it its accessible name, and `invalid` marks it as invalid without any message.

<Preview stack code={`<hx-input aria-label="Search" type="search" placeholder="Search"></hx-input>`} />

An `hx-date-range-picker` has two names: the field displays the errors of `start-name` and `end-name`.

## API

### hx-form-field

#### Properties

| Property          | Attribute          | Type                   | Default | Description                                                                                                   |
| ----------------- | ------------------ | ---------------------- | ------- | ------------------------------------------------------------------------------------------------------------- |
| `name`            | `name`             | `string`               | `""`    | Name of the control                                                                                           |
| `label`           | `label`            | `string`               | `""`    | Label displayed above the control                                                                             |
| `description`     | `description`      | `string`               | `""`    | Text under the label                                                                                          |
| `help`            | `help`             | `string`               | `""`    | Text of the tooltip on the help icon, at the end of the label row                                             |
| `hint`            | `hint`             | `string`               | `""`    | Help text under the control, replaced by `error` when set                                                     |
| `error`           | `error`            | `string`               | `""`    | Error message under the control; also marks the control as invalid                                            |
| `required`        | `required`         | `boolean`              | `false` | Adds an asterisk to the label and marks the control as required                                               |
| `eagerValidation` | `eager-validation` | `boolean`              | `false` | Inside `hx-form`, validates on `input` without waiting for the first blur                                     |
| `control`         | —                  | `HxFormFieldControl`   | —       | The form control of the field (read-only)                                                                     |
| `names`           | —                  | `string[]` (read-only) | —       | Names matched against the errors of `hx-form`: `name`, and the names of an `hx-date-range-picker` (read-only) |

#### Methods

| Name      | Description                    |
| --------- | ------------------------------ |
| `focus()` | Moves the focus to the control |

#### Events

| Name               | Description                                      |
| ------------------ | ------------------------------------------------ |
| `hx-field-connect` | The field found its control and gave it its name |

#### Slots

| Name          | Description                                             |
| ------------- | ------------------------------------------------------- |
| (default)     | The form control                                        |
| `label`       | Rich label, instead of the `label` property             |
| `description` | Rich description, instead of the `description` property |
| `help`        | Rich tooltip content, instead of the `help` property    |
| `hint`        | Rich hint, instead of the `hint` property               |
| `error`       | Rich error message, displayed while `error` is set      |

#### CSS parts

| Name          | Description                           |
| ------------- | ------------------------------------- |
| `label`       | The label                             |
| `value`       | The formatted value of an `hx-slider` |
| `help`        | The help button                       |
| `description` | The description                       |
| `hint`        | The hint                              |
| `error`       | The error message                     |
