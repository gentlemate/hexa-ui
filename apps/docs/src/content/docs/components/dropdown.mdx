## Structure

```html
<hx-dropdown>
    <hx-button slot="trigger"></hx-button>

    <hx-dropdown-group>
        <hx-dropdown-item></hx-dropdown-item>
    </hx-dropdown-group>

    <hx-dropdown-item></hx-dropdown-item>

    <hx-dropdown-item>
        <hx-dropdown-submenu>
            <hx-dropdown-item></hx-dropdown-item>
        </hx-dropdown-submenu>
    </hx-dropdown-item>

    <hx-dropdown-separator></hx-dropdown-separator>
</hx-dropdown>
```

## Keyboard

On the trigger, <kbd>Enter</kbd> / <kbd>Space</kbd> and <kbd>↓</kbd> open the menu on the first item, <kbd>↑</kbd> on the last one. <kbd>↑</kbd> / <kbd>↓</kbd> (looping), <kbd>Home</kbd> / <kbd>End</kbd> and typeahead navigate the items, <kbd>Enter</kbd> / <kbd>Space</kbd> activate them. Disabled items are skipped.

<kbd>→</kbd> opens a submenu and <kbd>←</kbd> closes it. <kbd>Escape</kbd> closes the current menu, <kbd>Tab</kbd>
closes the whole menu. When the menu closes, the focus returns to the trigger.

## API

### hx-dropdown

#### Properties

| Property    | Attribute   | Type                                                                                                                                                                 | Default          | Description                                                         |
| ----------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | ------------------------------------------------------------------- |
| `placement` | `placement` | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom-start"` | Position of the menu relative to the trigger                        |
| `disabled`  | `disabled`  | `boolean`                                                                                                                                                            | `false`          | Prevents the trigger from opening the menu                          |
| `distance`  | `distance`  | `number`                                                                                                                                                             | `4`              | Gap in pixels between the trigger and the popup                     |
| `open`      | `open`      | `boolean`                                                                                                                                                            | `false`          | Whether it is open. Setting it directly skips `hx-show` / `hx-hide` |

#### Methods

| Name     | Description                 |
| -------- | --------------------------- |
| `show()` | Opens it (fires `hx-show`)  |
| `hide()` | Closes it (fires `hx-hide`) |

#### Events

| Name            | Description                                                                                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hx-show`       | The menu is about to open. Cancelable                                                                                                                                           |
| `hx-after-show` | The menu is open and its enter animation finished                                                                                                                               |
| `hx-hide`       | The menu is about to close. Cancelable                                                                                                                                          |
| `hx-after-hide` | The menu is closed and its exit animation finished                                                                                                                              |
| `hx-select`     | An item was activated (fired by the `hx-dropdown-item`). Normal items close the menu, checkbox and radio items keep it open. Cancelable: `preventDefault()` keeps the menu open |

#### Slots

| Name      | Description                                                                      |
| --------- | -------------------------------------------------------------------------------- |
| `trigger` | The element that opens the menu (e.g. an `hx-button`)                            |
| (default) | The `hx-dropdown-item`, `hx-dropdown-group` and `hx-dropdown-separator` elements |

#### CSS custom properties

| Name                    | Default                   | Description               |
| ----------------------- | ------------------------- | ------------------------- |
| `--hx-spacing-dropdown` | `var(--hx-spacing-popup)` | Padding of the menu       |
| `--hx-radius-dropdown`  | `var(--hx-radius-popup)`  | Border radius of the menu |

#### CSS parts

| Name    | Description    |
| ------- | -------------- |
| `popup` | The menu panel |

### hx-dropdown-submenu

#### Properties

| Property    | Attribute   | Type                                                                                                                                                                 | Default         | Description                                                         |
| ----------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- | ------------------------------------------------------------------- |
| `placement` | `placement` | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"right-start"` | Position of the submenu relative to its item                        |
| `distance`  | `distance`  | `number`                                                                                                                                                             | `4`             | Gap in pixels between the item and the submenu                      |
| `open`      | `open`      | `boolean`                                                                                                                                                            | `false`         | Whether it is open. Setting it directly skips `hx-show` / `hx-hide` |

#### Methods

| Name     | Description                 |
| -------- | --------------------------- |
| `show()` | Opens it (fires `hx-show`)  |
| `hide()` | Closes it (fires `hx-hide`) |

#### Events

| Name            | Description                                        |
| --------------- | -------------------------------------------------- |
| `hx-show`       | The menu is about to open. Cancelable              |
| `hx-after-show` | The menu is open and its enter animation finished  |
| `hx-hide`       | The menu is about to close. Cancelable             |
| `hx-after-hide` | The menu is closed and its exit animation finished |

#### Slots

| Name      | Description                                                                      |
| --------- | -------------------------------------------------------------------------------- |
| (default) | The `hx-dropdown-item`, `hx-dropdown-group` and `hx-dropdown-separator` elements |

#### CSS parts

| Name    | Description    |
| ------- | -------------- |
| `popup` | The menu panel |

### hx-dropdown-item

#### Properties

| Property   | Attribute  | Type                                | Default     | Description                                                          |
| ---------- | ---------- | ----------------------------------- | ----------- | -------------------------------------------------------------------- |
| `type`     | `type`     | `"normal" \| "checkbox" \| "radio"` | `"normal"`  | `checkbox` and `radio` items toggle `checked` and keep the menu open |
| `checked`  | `checked`  | `boolean`                           | `false`     | Whether a checkbox or radio item is checked                          |
| `variant`  | `variant`  | `"default" \| "destructive"`        | `"default"` | `destructive` shows the item in the destructive color                |
| `icon`     | —          | `IconNode`                          | —           | Lucide icon, set as a JS property                                    |
| `value`    | `value`    | `string`                            | `""`        | Sent as `event.detail.value` in `hx-select`                          |
| `disabled` | `disabled` | `boolean`                           | `false`     | Prevents activating the item                                         |

#### Events

| Name        | Description                                                                                                                                                                                                               |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hx-select` | The item was activated; `event.detail` is `{ item, value }`. Cancelable: `preventDefault()` keeps the menu open (checkbox and radio items keep it open anyway). Checkbox and radio items update `checked` before it fires |

#### Slots

| Name      | Description                                                                 |
| --------- | --------------------------------------------------------------------------- |
| (default) | The item label, and an optional `hx-dropdown-submenu` opened from this item |

#### CSS parts

| Name        | Description                                       |
| ----------- | ------------------------------------------------- |
| `base`      | The item wrapper                                  |
| `indicator` | The check mark or dot of checkbox and radio items |
| `icon`      | The `hx-icon` rendered from the `icon` property   |
| `chevron`   | The chevron of an item with a submenu             |

#### CSS states

| Name       | Description                     |
| ---------- | ------------------------------- |
| `expanded` | The submenu of the item is open |

### hx-dropdown-group

#### Properties

| Property | Attribute | Type     | Default | Description                                    |
| -------- | --------- | -------- | ------- | ---------------------------------------------- |
| `label`  | `label`   | `string` | `""`    | Heading of the group, also its accessible name |

#### Slots

| Name      | Description                                                                           |
| --------- | ------------------------------------------------------------------------------------- |
| (default) | The grouped `hx-dropdown-item` elements. Radio items are exclusive within their group |

#### CSS parts

| Name    | Description                                     |
| ------- | ----------------------------------------------- |
| `label` | The group heading, rendered when `label` is set |

### hx-dropdown-separator

#### CSS parts

| Name   | Description        |
| ------ | ------------------ |
| `line` | The separator line |
