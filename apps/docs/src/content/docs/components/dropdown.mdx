## Structure

```html
<oui-dropdown>
    <oui-button slot="trigger"></oui-button>

    <oui-dropdown-group>
        <oui-dropdown-item></oui-dropdown-item>
    </oui-dropdown-group>

    <oui-dropdown-item></oui-dropdown-item>

    <oui-dropdown-item>
        <oui-dropdown-submenu>
            <oui-dropdown-item></oui-dropdown-item>
        </oui-dropdown-submenu>
    </oui-dropdown-item>

    <oui-dropdown-separator></oui-dropdown-separator>
</oui-dropdown>
```

## Keyboard

On the trigger, <kbd>Enter</kbd> / <kbd>Space</kbd> and <kbd>↓</kbd> open the menu on the first item, <kbd>↑</kbd> on the last one. <kbd>↑</kbd> / <kbd>↓</kbd> (looping), <kbd>Home</kbd> / <kbd>End</kbd> and typeahead navigate the items, <kbd>Enter</kbd> / <kbd>Space</kbd> activate them. Disabled items are skipped.

<kbd>→</kbd> opens a submenu and <kbd>←</kbd> closes it. <kbd>Escape</kbd> closes the current menu, <kbd>Tab</kbd>
closes the whole menu. When the menu closes, the focus returns to the trigger.

## API

### oui-dropdown

#### Properties

| Property    | Attribute   | Type                                                                                                                                                                 | Default          | Description                                                           |
| ----------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | --------------------------------------------------------------------- |
| `placement` | `placement` | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom-start"` | Position of the menu relative to the trigger                          |
| `disabled`  | `disabled`  | `boolean`                                                                                                                                                            | `false`          | Prevents the trigger from opening the menu                            |
| `distance`  | `distance`  | `number`                                                                                                                                                             | `4`              | Gap in pixels between the trigger and the popup                       |
| `open`      | `open`      | `boolean`                                                                                                                                                            | `false`          | Whether it is open. Setting it directly skips `oui-show` / `oui-hide` |

#### Methods

| Name     | Description                  |
| -------- | ---------------------------- |
| `show()` | Opens it (fires `oui-show`)  |
| `hide()` | Closes it (fires `oui-hide`) |

#### Events

| Name             | Description                                                                                                                                                                      |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `oui-show`       | The menu is about to open. Cancelable                                                                                                                                            |
| `oui-after-show` | The menu is open and its enter animation finished                                                                                                                                |
| `oui-hide`       | The menu is about to close. Cancelable                                                                                                                                           |
| `oui-after-hide` | The menu is closed and its exit animation finished                                                                                                                               |
| `oui-select`     | An item was activated (fired by the `oui-dropdown-item`). Normal items close the menu, checkbox and radio items keep it open. Cancelable: `preventDefault()` keeps the menu open |

#### Slots

| Name      | Description                                                                         |
| --------- | ----------------------------------------------------------------------------------- |
| `trigger` | The element that opens the menu (e.g. an `oui-button`)                              |
| (default) | The `oui-dropdown-item`, `oui-dropdown-group` and `oui-dropdown-separator` elements |

#### CSS custom properties

| Name                     | Default                    | Description               |
| ------------------------ | -------------------------- | ------------------------- |
| `--oui-spacing-dropdown` | `var(--oui-spacing-popup)` | Padding of the menu       |
| `--oui-radius-dropdown`  | `var(--oui-radius-popup)`  | Border radius of the menu |

#### CSS parts

| Name    | Description    |
| ------- | -------------- |
| `popup` | The menu panel |

### oui-dropdown-submenu

#### Properties

| Property    | Attribute   | Type                                                                                                                                                                 | Default         | Description                                                           |
| ----------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- | --------------------------------------------------------------------- |
| `placement` | `placement` | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"right-start"` | Position of the submenu relative to its item                          |
| `distance`  | `distance`  | `number`                                                                                                                                                             | `4`             | Gap in pixels between the item and the submenu                        |
| `open`      | `open`      | `boolean`                                                                                                                                                            | `false`         | Whether it is open. Setting it directly skips `oui-show` / `oui-hide` |

#### Methods

| Name     | Description                  |
| -------- | ---------------------------- |
| `show()` | Opens it (fires `oui-show`)  |
| `hide()` | Closes it (fires `oui-hide`) |

#### Events

| Name             | Description                                        |
| ---------------- | -------------------------------------------------- |
| `oui-show`       | The menu is about to open. Cancelable              |
| `oui-after-show` | The menu is open and its enter animation finished  |
| `oui-hide`       | The menu is about to close. Cancelable             |
| `oui-after-hide` | The menu is closed and its exit animation finished |

#### Slots

| Name      | Description                                                                         |
| --------- | ----------------------------------------------------------------------------------- |
| (default) | The `oui-dropdown-item`, `oui-dropdown-group` and `oui-dropdown-separator` elements |

#### CSS parts

| Name    | Description    |
| ------- | -------------- |
| `popup` | The menu panel |

### oui-dropdown-item

#### Properties

| Property   | Attribute  | Type                                | Default     | Description                                                          |
| ---------- | ---------- | ----------------------------------- | ----------- | -------------------------------------------------------------------- |
| `type`     | `type`     | `"normal" \| "checkbox" \| "radio"` | `"normal"`  | `checkbox` and `radio` items toggle `checked` and keep the menu open |
| `checked`  | `checked`  | `boolean`                           | `false`     | Whether a checkbox or radio item is checked                          |
| `variant`  | `variant`  | `"default" \| "destructive"`        | `"default"` | `destructive` shows the item in the destructive color                |
| `icon`     | —          | `IconNode`                          | —           | Lucide icon, set as a JS property                                    |
| `value`    | `value`    | `string`                            | `""`        | Sent as `event.detail.value` in `oui-select`                         |
| `disabled` | `disabled` | `boolean`                           | `false`     | Prevents activating the item                                         |

#### Events

| Name         | Description                                                                                                                                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `oui-select` | The item was activated; `event.detail` is `{ item, value }`. Cancelable: `preventDefault()` keeps the menu open (checkbox and radio items keep it open anyway). Checkbox and radio items update `checked` before it fires |

#### Slots

| Name      | Description                                                                  |
| --------- | ---------------------------------------------------------------------------- |
| (default) | The item label, and an optional `oui-dropdown-submenu` opened from this item |

#### CSS parts

| Name        | Description                                       |
| ----------- | ------------------------------------------------- |
| `base`      | The item wrapper                                  |
| `indicator` | The check mark or dot of checkbox and radio items |
| `icon`      | The `oui-icon` rendered from the `icon` property  |
| `chevron`   | The chevron of an item with a submenu             |

#### CSS states

| Name       | Description                     |
| ---------- | ------------------------------- |
| `expanded` | The submenu of the item is open |

### oui-dropdown-group

#### Slots

| Name      | Description                                                                            |
| --------- | -------------------------------------------------------------------------------------- |
| (default) | The grouped `oui-dropdown-item` elements. Radio items are exclusive within their group |

#### CSS parts

| Name    | Description                                     |
| ------- | ----------------------------------------------- |
| `label` | The group heading, rendered when `label` is set |

### oui-dropdown-separator

#### CSS parts

| Name   | Description        |
| ------ | ------------------ |
