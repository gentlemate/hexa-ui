## API

### hx-skeleton

#### Properties

| Property | Attribute | Type      | Default | Description                             |
| -------- | --------- | --------- | ------- | --------------------------------------- |
| `circle` | `circle`  | `boolean` | `false` | Fully rounded shape, e.g. for an avatar |

#### CSS custom properties

| Name                   | Default                  | Description   |
| ---------------------- | ------------------------ | ------------- |
| `--hx-radius-skeleton` | `var(--hx-radius-panel)` | Border radius |

#### CSS parts

| Name   | Description       |
| ------ | ----------------- |
| `base` | The pulsing block |
