### Format

`value` accepts hex, `rgb()`, `hsl()` and `oklch()` colors, whatever the `format`. Once the user edits the color, it is converted to `format`: `hex` (default), `rgb`, `hsl` or `oklch`.

<Preview
    stack
    code={`<hx-color-picker label="HEX" value="#2b7fff"></hx-color-picker>
<hx-color-picker label="RGB" format="rgb" value="rgb(43 127 255)"></hx-color-picker>
<hx-color-picker label="HSL" format="hsl" value="hsl(216 100% 58%)"></hx-color-picker>
<hx-color-picker label="OKLCH" format="oklch" value="oklch(0.623 0.214 259.815)"></hx-color-picker>`}
/>

### Format select

`format-select` adds a select in the popup to display the color in another format. It only changes the text field: `value` stays in `format`, and changing the format fires no event.

<Preview stack code={`<hx-color-picker label="Brand" value="#2b7fff" format-select></hx-color-picker>`} />

### Alpha

`alpha` adds a transparency slider. Without it, the transparency of the color is dropped once the user edits it.

<Preview stack code={`<hx-color-picker label="Overlay" value="#2b7fff80" alpha></hx-color-picker>`} />

### Swatches

`swatches` takes a JSON array of colors, offered in the popup. `swatch-size` sets their size: `xs`, `sm` (default), `md`, `lg` or `xl`.

<Preview
    stack
    code={`<hx-color-picker label="Brand" value="#2b7fff" swatches='["#fb2c36", "#fe9a00", "#00c950", "#2b7fff", "#ad46ff"]'></hx-color-picker>`}
/>

## Behavior

The popup stays open while the color changes, and closes with Escape, a click outside or when the focus leaves it. `input` fires while dragging and `change` once the pointer is released, so listen to `input` for a live preview.

In the area, the left and right arrows change the saturation and the up and down arrows the brightness. In the sliders, all the arrows change the value. Page Up and Page Down take bigger steps, Home and End go to the bounds.

The controls work in sRGB. `value` is kept as is until the user edits it, so an `oklch()` color outside the sRGB gamut is not altered by opening the popup, but editing it brings it back into sRGB.

## API

### hx-color-picker

#### Properties

| Property       | Attribute       | Type                                                                                                                                                                 | Default          | Description                                                                                        |
| -------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------------------- |
| `name`         | `name`          | `string`                                                                                                                                                             | `""`             | Name submitted with the form                                                                       |
| `value`        | `value`         | `string`                                                                                                                                                             | `""`             | Selected color, as a hex, `rgb()`, `hsl()` or `oklch()` string; kept as is until the user edits it |
| `format`       | `format`        | `"hex" \| "rgb" \| "hsl" \| "oklch"`                                                                                                                                 | `"hex"`          | Format of the value once the user edits it                                                         |
| `alpha`        | `alpha`         | `boolean`                                                                                                                                                            | `false`          | Shows the transparency slider and keeps the transparency of the color                              |
| `swatches`     | `swatches`      | `string[]`                                                                                                                                                           | `[]`             | Colors offered in the popup, as JSON in the attribute                                              |
| `swatchSize`   | `swatch-size`   | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`                                                                                                                               | `"sm"`           | Size of the swatches in the popup                                                                  |
| `formatSelect` | `format-select` | `boolean`                                                                                                                                                            | `false`          | Shows a select in the popup to display the color in another format; `value` stays in `format`      |
| `placement`    | `placement`     | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom-start"` | Position of the popup relative to the trigger                                                      |
| `distance`     | `distance`      | `number`                                                                                                                                                             | `4`              | Gap in pixels between the trigger and the popup                                                    |
| `label`        | `label`         | `string`                                                                                                                                                             | `""`             | Label displayed above the field                                                                    |
| `placeholder`  | `placeholder`   | `string`                                                                                                                                                             | `""`             | Text shown when nothing is selected                                                                |
| `hint`         | `hint`          | `string`                                                                                                                                                             | `""`             | Help text under the field, replaced by `error` when set                                            |
| `error`        | `error`         | `string`                                                                                                                                                             | `""`             | Error message under the field; also marks the field as invalid                                     |
| `disabled`     | `disabled`      | `boolean`                                                                                                                                                            | `false`          | Prevents user interaction                                                                          |
| `required`     | `required`      | `boolean`                                                                                                                                                            | `false`          | Adds an asterisk to the label and marks the field as required for assistive technologies           |
| `focusTarget`  | —               | `HTMLButtonElement`                                                                                                                                                  | —                | The inner element that receives the focus (read-only)                                              |
| `open`         | `open`          | `boolean`                                                                                                                                                            | `false`          | Whether it is open. Setting it directly skips `hx-show` / `hx-hide`                                |

#### Methods

| Name     | Description                 |
| -------- | --------------------------- |
| `show()` | Opens it (fires `hx-show`)  |
| `hide()` | Closes it (fires `hx-hide`) |

#### Events

| Name            | Description                                                          |
| --------------- | -------------------------------------------------------------------- |
| `input`         | The color changed, while dragging or from the keyboard               |
| `change`        | The color changed, once the pointer is released or from the keyboard |
| `hx-show`       | The popup is about to open. Cancelable                               |
| `hx-after-show` | The popup is open and its enter animation finished                   |
| `hx-hide`       | The popup is about to close. Cancelable                              |
| `hx-after-hide` | The popup is closed and its exit animation finished                  |

#### CSS custom properties

| Name                        | Default                   | Description                                         |
| --------------------------- | ------------------------- | --------------------------------------------------- |
| `--hx-height-color-picker`  | `var(--hx-height-field)`  | Height of the trigger                               |
| `--hx-spacing-color-picker` | `var(--hx-spacing-field)` | Horizontal padding of the trigger                   |
| `--hx-radius-color-picker`  | `var(--hx-radius-field)`  | Border radius of the trigger                        |
| `--hx-width-color-popup`    | `16rem`                   | Width of the popup                                  |
| `--hx-spacing-color-popup`  | `0.75rem`                 | Padding of the popup                                |
| `--hx-height-color-area`    | `10rem`                   | Height of the saturation and brightness area        |
| `--hx-radius-color-area`    | `var(--hx-radius-field)`  | Border radius of the saturation and brightness area |
| `--hx-height-color-slider`  | `0.75rem`                 | Height of the hue and transparency sliders          |
| `--hx-radius-color-slider`  | `var(--hx-radius-pill)`   | Border radius of the hue and transparency sliders   |
| `--hx-size-color-thumb`     | `1.25rem`                 | Size of the thumbs                                  |
| `--hx-radius-color-thumb`   | `var(--hx-radius-pill)`   | Border radius of the thumbs                         |
| `--hx-size-color-swatch`    | `1.25rem`                 | Size of the preview in the trigger and the field    |
| `--hx-radius-color-swatch`  | `var(--hx-radius-pill)`   | Border radius of the preview and the swatches       |

#### CSS parts

| Name          | Description                                                                  |
| ------------- | ---------------------------------------------------------------------------- |
| `trigger`     | The button showing the selected color                                        |
| `swatch`      | The preview of the color in the trigger                                      |
| `value`       | The selected color, or the placeholder                                       |
| `popup`       | The panel holding the controls                                               |
| `area`        | The saturation and brightness area                                           |
| `area-thumb`  | The thumb of the area                                                        |
| `hue`         | The hue slider                                                               |
| `hue-thumb`   | The thumb of the hue slider                                                  |
| `alpha`       | The transparency slider, shown with `alpha`                                  |
| `alpha-thumb` | The thumb of the transparency slider                                         |
| `swatches`    | The `hx-color-swatch-picker`, shown with `swatches`                          |
| `preset`      | An `hx-color-swatch` of the list                                             |
| `formats`     | The `hx-select` choosing the format of the field, shown with `format-select` |
| `field`       | The `hx-color-field`                                                         |
