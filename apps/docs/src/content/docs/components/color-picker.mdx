## Import

```js
import "onent-ui/color-picker";
import "onent-ui/form-field";
```

The label, the description, the hint and the error come from [`oui-form-field`](../form-field/).

<Preview
    stack
    code={`<oui-form-field label="Brand">
    <oui-color-picker placeholder="Pick a color"></oui-color-picker>
</oui-form-field>`}
/>

## Structure

```html
<oui-color-picker></oui-color-picker>
```

## Examples

### Format

`value` accepts hex, `rgb()`, `hsl()` and `oklch()` colors, whatever the `format`. Once the user edits the color, it is converted to `format`: `hex` (default), `rgb`, `hsl` or `oklch`.

<Preview
    stack
    code={`<oui-form-field label="HEX">
    <oui-color-picker value="#2b7fff"></oui-color-picker>
</oui-form-field>
<oui-form-field label="RGB">
    <oui-color-picker format="rgb" value="rgb(43 127 255)"></oui-color-picker>
</oui-form-field>
<oui-form-field label="HSL">
    <oui-color-picker format="hsl" value="hsl(216 100% 58%)"></oui-color-picker>
</oui-form-field>
<oui-form-field label="OKLCH">
    <oui-color-picker format="oklch" value="oklch(0.623 0.214 259.815)"></oui-color-picker>
</oui-form-field>`}
/>

### Format select

`format-select` adds a select in the popup to display the color in another format. It only changes the text field: `value` stays in `format`, and changing the format fires no event.

<Preview
    stack
    code={`<oui-form-field label="Brand">
    <oui-color-picker value="#2b7fff" format-select></oui-color-picker>
</oui-form-field>`}
/>

### Alpha

`alpha` adds a transparency slider. Without it, the transparency of the color is dropped once the user edits it.

<Preview
    stack
    code={`<oui-form-field label="Overlay">
    <oui-color-picker value="#2b7fff80" alpha></oui-color-picker>
</oui-form-field>`}
/>

### Swatches

`swatches` takes a JSON array of colors, offered in the popup. `swatch-size` sets their size: `xs`, `sm` (default), `md`, `lg` or `xl`.

<Preview
    stack
    code={`<oui-form-field label="Brand">
    <oui-color-picker value="#2b7fff" swatches='["#fb2c36", "#fe9a00", "#00c950", "#2b7fff", "#ad46ff"]'></oui-color-picker>
</oui-form-field>`}
/>

<Preview stack code={`<oui-color-picker aria-label="Disabled" value="#00c950" disabled></oui-color-picker>`} />

### Invalid

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`oui-form-field`](../form-field/#error).

<Preview stack code={`<oui-color-picker aria-label="Invalid" invalid></oui-color-picker>`} />

### Form

`name` submits `value` with the form.

<Preview
    stack
    code={`<form onsubmit="event.preventDefault(); this.querySelector('p').textContent = 'brand=' + new FormData(this).get('brand')">

/>

### Form field

In a form, [`oui-form-field`](../form-field/) adds the label, the hint and the error message.

<Preview
    stack
    code={`<oui-form-field label="Brand" hint="Used throughout your app.">
    <oui-color-picker placeholder="Pick a color"></oui-color-picker>
</oui-form-field>
<oui-form-field label="Destructive" error="This color is not accessible.">
    <oui-color-picker value="#fb2c36"></oui-color-picker>
</oui-form-field>`}
/>

## Behavior

The popup stays open while the color changes, and closes with Escape, a click outside or when the focus leaves it. `input` fires while dragging and `change` once the pointer is released, so listen to `input` for a live preview.

In the area, the left and right arrows change the saturation and the up and down arrows the brightness. In the sliders, all the arrows change the value. Page Up and Page Down take bigger steps, Home and End go to the bounds.

The controls work in sRGB. `value` is kept as is until the user edits it, so an `oklch()` color outside the sRGB gamut is not altered by opening the popup, but editing it brings it back into sRGB.

## API

### oui-color-picker

#### Properties

| Property       | Attribute       | Type                                                                                                                                                                 | Default          | Description                                                                                        |
| -------------- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | -------------------------------------------------------------------------------------------------- |
| `name`         | `name`          | `string`                                                                                                                                                             | `""`             | Name submitted with the form                                                                       |
| `value`        | `value`         | `string`                                                                                                                                                             | `""`             | Selected color, as a hex, `rgb()`, `hsl()` or `oklch()` string; kept as is until the user edits it |
| `format`       | `format`        | `"hex" \| "rgb" \| "hsl" \| "oklch"`                                                                                                                                 | `"hex"`          | Format of the value once the user edits it                                                         |
| `alpha`        | `alpha`         | `boolean`                                                                                                                                                            | `false`          | Shows the transparency slider and keeps the transparency of the color                              |
| `swatches`     | `swatches`      | `string[]`                                                                                                                                                           | `[]`             | Colors offered in the popup, as JSON in the attribute                                              |
| `swatchSize`   | `swatch-size`   | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`                                                                                                                               | `"sm"`           | Size of the swatches in the popup                                                                  |
| `formatSelect` | `format-select` | `boolean`                                                                                                                                                            | `false`          | Shows a select in the popup to display the color in another format; `value` stays in `format`      |
| `placement`    | `placement`     | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom-start"` | Position of the popup relative to the trigger                                                      |
| `distance`     | `distance`      | `number`                                                                                                                                                             | `4`              | Gap in pixels between the trigger and the popup                                                    |
| `placeholder`  | `placeholder`   | `string`                                                                                                                                                             | `""`             | Text shown when nothing is selected                                                                |
| `disabled`     | `disabled`      | `boolean`                                                                                                                                                            | `false`          | Prevents user interaction                                                                          |
| `required`     | `required`      | `boolean`                                                                                                                                                            | `false`          | Marks the field as required for form validation                                                    |
| `invalid`      | `invalid`       | `boolean`                                                                                                                                                            | `false`          | Marks the field as invalid without displaying a message                                            |
| `ariaLabel`    | `aria-label`    | `string \| null`                                                                                                                                                     | `null`           | Accessible name of the field, set with the `aria-label` attribute                                  |
| `focusTarget`  | —               | `HTMLButtonElement`                                                                                                                                                  | —                | The inner element that receives the focus (read-only)                                              |
| `open`         | `open`          | `boolean`                                                                                                                                                            | `false`          | Whether it is open. Setting it directly skips `oui-show` / `oui-hide`                              |

#### Methods

| Name     | Description                  |
| -------- | ---------------------------- |
| `show()` | Opens it (fires `oui-show`)  |
| `hide()` | Closes it (fires `oui-hide`) |

#### Events

| Name             | Description                                                          |
| ---------------- | -------------------------------------------------------------------- |
| `input`          | The color changed, while dragging or from the keyboard               |
| `change`         | The color changed, once the pointer is released or from the keyboard |
| `oui-show`       | The popup is about to open. Cancelable                               |
| `oui-after-show` | The popup is open and its enter animation finished                   |
| `oui-hide`       | The popup is about to close. Cancelable                              |
| `oui-after-hide` | The popup is closed and its exit animation finished                  |

#### CSS custom properties

| Name                         | Default                                | Description                                         |
| ---------------------------- | -------------------------------------- | --------------------------------------------------- |
| `--oui-height-color-picker`  | `var(--oui-height-field)`              | Height of the trigger                               |
| `--oui-spacing-color-picker` | `var(--oui-spacing-field)`             | Horizontal padding of the trigger                   |
| `--oui-radius-color-picker`  | `var(--oui-radius-field)`              | Border radius of the trigger                        |
| `--oui-width-color-popup`    | `16rem`                                | Width of the popup                                  |
| `--oui-spacing-color-popup`  | `0.75rem`                              | Padding of the popup                                |
| `--oui-height-color-area`    | `10rem`                                | Height of the saturation and brightness area        |
| `--oui-radius-color-area`    | `min(var(--oui-radius-panel), 0.5rem)` | Border radius of the saturation and brightness area |
| `--oui-height-color-slider`  | `0.75rem`                              | Height of the hue and transparency sliders          |
| `--oui-radius-color-slider`  | `var(--oui-radius-pill)`               | Border radius of the hue and transparency sliders   |
| `--oui-size-color-thumb`     | `1.25rem`                              | Size of the thumbs                                  |
| `--oui-radius-color-thumb`   | `var(--oui-radius-pill)`               | Border radius of the thumbs                         |
| `--oui-size-color-swatch`    | `1.25rem`                              | Size of the preview in the trigger and the field    |
| `--oui-radius-color-swatch`  | `var(--oui-radius-pill)`               | Border radius of the preview and the swatches       |

#### CSS parts

| Name          | Description                                                                   |
| ------------- | ----------------------------------------------------------------------------- |
| `trigger`     | The button showing the selected color                                         |
| `swatch`      | The preview of the color in the trigger                                       |
| `value`       | The selected color, or the placeholder                                        |
| `popup`       | The panel holding the controls                                                |
| `area`        | The saturation and brightness area                                            |
| `area-thumb`  | The thumb of the area                                                         |
| `hue`         | The hue slider                                                                |
| `hue-thumb`   | The thumb of the hue slider                                                   |
| `alpha`       | The transparency slider, shown with `alpha`                                   |
| `alpha-thumb` | The thumb of the transparency slider                                          |
| `swatches`    | The `oui-color-swatch-picker`, shown with `swatches`                          |
| `preset`      | An `oui-color-swatch` of the list                                             |
| `formats`     | The `oui-select` choosing the format of the field, shown with `format-select` |
| `field`       | The `oui-color-field`                                                         |
