## Import

```js
import "hexa-ui/select";
import "hexa-ui/form-field";
```

The label, the description, the hint and the error come from [`hx-form-field`](../form-field/).

## Structure

```html
<hx-select>
    <hx-select-group>
        <hx-select-option></hx-select-option>
    </hx-select-group>

    <hx-select-option></hx-select-option>

    <hx-select-separator></hx-select-separator>
</hx-select>
```

## Keyboard

The trigger opens a listbox and moves the focus to the selected option. <kbd>↑</kbd> / <kbd>↓</kbd>, <kbd>Home</kbd> / <kbd>End</kbd> and typeahead navigate the options, <kbd>Enter</kbd> / <kbd>Space</kbd> select. On the closed trigger, typeahead and <kbd>Home</kbd> / <kbd>End</kbd> select directly.

## API

### hx-select

#### Properties

| Property      | Attribute     | Type                                                                                                                                                                 | Default          | Description                                                         |
| ------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- | ------------------------------------------------------------------- |
| `name`        | `name`        | `string`                                                                                                                                                             | `""`             | Name submitted with the form                                        |
| `value`       | `value`       | `string`                                                                                                                                                             | `""`             | Value of the selected option                                        |
| `placeholder` | `placeholder` | `string`                                                                                                                                                             | `""`             | Text shown when no option is selected                               |
| `placement`   | `placement`   | `"top" \| "right" \| "bottom" \| "left" \| "top-start" \| "top-end" \| "right-start" \| "right-end" \| "bottom-start" \| "bottom-end" \| "left-start" \| "left-end"` | `"bottom-start"` | Position of the listbox relative to the trigger                     |
| `distance`    | `distance`    | `number`                                                                                                                                                             | `4`              | Gap in pixels between the trigger and the listbox                   |
| `disabled`    | `disabled`    | `boolean`                                                                                                                                                            | `false`          | Prevents user interaction                                           |
| `required`    | `required`    | `boolean`                                                                                                                                                            | `false`          | Marks the field as required for form validation                     |
| `invalid`     | `invalid`     | `boolean`                                                                                                                                                            | `false`          | Marks the field as invalid without displaying a message             |
| `ariaLabel`   | `aria-label`  | `string \| null`                                                                                                                                                     | `null`           | Accessible name of the field, set with the `aria-label` attribute   |
| `focusTarget` | —             | `HTMLButtonElement`                                                                                                                                                  | —                | The inner element that receives the focus (read-only)               |
| `open`        | `open`        | `boolean`                                                                                                                                                            | `false`          | Whether it is open. Setting it directly skips `hx-show` / `hx-hide` |

#### Methods

| Name     | Description                 |
| -------- | --------------------------- |
| `show()` | Opens it (fires `hx-show`)  |
| `hide()` | Closes it (fires `hx-hide`) |

#### Events

| Name            | Description                                           |
| --------------- | ----------------------------------------------------- |
| `input`         | The user selected another option                      |
| `change`        | The user selected another option                      |
| `hx-show`       | The listbox is about to open. Cancelable              |
| `hx-after-show` | The listbox is open and its enter animation finished  |
| `hx-hide`       | The listbox is about to close. Cancelable             |
| `hx-after-hide` | The listbox is closed and its exit animation finished |

#### Slots

| Name      | Description                                                                  |
| --------- | ---------------------------------------------------------------------------- |
| (default) | The `hx-select-option`, `hx-select-group` and `hx-select-separator` elements |

#### CSS custom properties

| Name                  | Default                   | Description                       |
| --------------------- | ------------------------- | --------------------------------- |
| `--hx-height-select`  | `var(--hx-height-field)`  | Height of the trigger             |
| `--hx-spacing-select` | `var(--hx-spacing-field)` | Horizontal padding of the trigger |
| `--hx-radius-select`  | `var(--hx-radius-field)`  | Border radius of the trigger      |

#### CSS parts

| Name      | Description                                   |
| --------- | --------------------------------------------- |
| `trigger` | The button showing the selected option        |
| `value`   | The selected option label, or the placeholder |
| `chevron` | The chevron of the trigger                    |
| `popup`   | The listbox panel                             |

### hx-select-option

#### Properties

| Property   | Attribute  | Type      | Default | Description                                             |
| ---------- | ---------- | --------- | ------- | ------------------------------------------------------- |
| `selected` | `selected` | `boolean` | `false` | Whether the option is selected (set by the `hx-select`) |
| `value`    | `value`    | `string`  | `""`    | Value of the option                                     |
| `disabled` | `disabled` | `boolean` | `false` | Prevents selecting the option                           |

#### Slots

| Name      | Description      |
| --------- | ---------------- |
| (default) | The option label |

#### CSS parts

| Name        | Description                           |
| ----------- | ------------------------------------- |
| `base`      | The option wrapper                    |
| `indicator` | The check mark of the selected option |

### hx-select-group

#### Properties

| Property | Attribute | Type     | Default | Description                                    |
| -------- | --------- | -------- | ------- | ---------------------------------------------- |
| `label`  | `label`   | `string` | `""`    | Heading of the group, also its accessible name |

#### Slots

| Name      | Description                             |
| --------- | --------------------------------------- |
| (default) | The grouped `hx-select-option` elements |

#### CSS parts

| Name    | Description                                     |
| ------- | ----------------------------------------------- |
| `label` | The group heading, rendered when `label` is set |

### hx-select-separator

#### CSS parts

| Name   | Description        |
| ------ | ------------------ |
| `line` | The separator line |
