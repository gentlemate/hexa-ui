<Preview

### Invalid

`invalid` marks the field as invalid, without any message. To display a message, use the `error` of [`oui-form-field`](../form-field/#error).

<Preview code={`<oui-switch invalid>Invalid</oui-switch>`} />

### Change event

`change` fires each time the switch is toggled.

<Preview code={`<oui-switch onchange="this.textContent = this.checked ? 'On' : 'Off'">Off</oui-switch>`} />

## Keyboard

<kbd>Space</kbd> toggles the switch.

## API

### oui-switch

#### Properties

| Property   | Attribute  | Type      | Default | Description                                              |
| ---------- | ---------- | --------- | ------- | -------------------------------------------------------- |
| `value`    | `value`    | `string`  | `"on"`  | Value submitted with the form when on                    |
| `checked`  | `checked`  | `boolean` | `false` | Whether the switch is on (not reflected as an attribute) |
| `name`     | `name`     | `string`  | `""`    | Name submitted with the form                             |
| `disabled` | `disabled` | `boolean` | `false` | Prevents user interaction                                |
| `required` | `required` | `boolean` | `false` | Marks the field as required for form validation          |
| `invalid`  | `invalid`  | `boolean` | `false` | Marks the field as invalid without displaying a message  |

#### Events

| Name     | Description               |
| -------- | ------------------------- |
| `input`  | The checked state changed |
| `change` | The checked state changed |

#### Slots

| Name      | Description      |
| --------- | ---------------- |
| (default) | The switch label |

#### CSS custom properties

| Name                        | Default                    | Description                                       |
| --------------------------- | -------------------------- | ------------------------------------------------- |
| `--oui-size-switch`         | `1.25rem`                  | Size of the thumb. The track is twice as wide     |
| `--oui-spacing-switch`      | `1px`                      | Space between the thumb and the edge of the track |
| `--oui-radius-switch`       | `var(--oui-radius-pill)`   | Border radius of the track                        |
| `--oui-radius-switch-thumb` | `var(--oui-radius-switch)` | Border radius of the thumb                        |

#### CSS parts

| Name      | Description       |
| --------- | ----------------- |
| `control` | The track         |
| `thumb`   | The sliding thumb |
| `label`   | The label wrapper |

#### CSS states

| Name      | Description      |
| --------- | ---------------- |
| `checked` | The switch is on |
