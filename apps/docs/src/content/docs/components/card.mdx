    <oui-card-header>

## API

### oui-card

#### Properties

| Property  | Attribute | Type                                | Default     | Description  |
| --------- | --------- | ----------------------------------- | ----------- | ------------ |
| `variant` | `variant` | `"default" \| "outline" \| "ghost"` | `"default"` | Visual style |

#### Slots

| Name      | Description                                                                    |
| --------- | ------------------------------------------------------------------------------ |
| (default) | The card sections: `oui-card-header`, `oui-card-content` and `oui-card-footer` |

#### CSS custom properties

| Name                 | Default                    | Description   |
| -------------------- | -------------------------- | ------------- |
| `--oui-spacing-card` | `var(--oui-spacing-panel)` | Padding       |
| `--oui-radius-card`  | `var(--oui-radius-panel)`  | Border radius |

#### CSS parts

| Name   | Description        |
| ------ | ------------------ |
| `base` | The card container |

### oui-card-header

#### Slots

| Name      | Description                                                                                     |
| --------- | ----------------------------------------------------------------------------------------------- |
| (default) | The `oui-card-title`, `oui-card-description` and `oui-card-action` elements, or a custom header |

### oui-card-title

#### Slots

| Name      | Description    |
| --------- | -------------- |
| (default) | The card title |

### oui-card-description

#### Slots

| Name      | Description                  |
| --------- | ---------------------------- |
| (default) | A short text under the title |

### oui-card-action

#### Slots

| Name      | Description                                                                   |
| --------- | ----------------------------------------------------------------------------- |
| (default) | An element aligned to the top right of the `oui-card-header` (button, badge…) |

### oui-card-content

#### Slots

| Name      | Description      |
| --------- | ---------------- |
| (default) | The card content |

### oui-card-footer

#### Slots

| Name      | Description                |
| --------- | -------------------------- |
| (default) | The card footer (actions…) |
