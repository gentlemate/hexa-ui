### Size

`size` sets the size of the swatches: `xs`, `sm`, `md`, `lg` or `xl`. The gap follows the size. Without `size`, `--hx-size-color-swatch-picker` and `--hx-gap-color-swatch-picker` apply.

| Size | Swatch   | Gap        |
| ---- | -------- | ---------- |
| `xs` | `1rem`   | `0.5rem`   |
| `sm` | `1.5rem` | `0.5rem`   |
| `md` | `2rem`   | `0.625rem` |
| `lg` | `2.5rem` | `0.75rem`  |
| `xl` | `3rem`   | `0.75rem`  |

### Invalid

`invalid` marks the field as invalid for assistive technologies, without any message or visual change. To display a message, use the `error` of [`hx-form-field`](../form-field/#error).

## Behavior

The group is a single tab stop. The arrow keys move the focus and select the swatch, skipping the disabled ones and wrapping at the ends. In a `grid`, the up and down arrows move by a row. Home and End go to the first and last swatches, and Space selects the focused one.

`value` is compared as written with the `value` of the swatches, so `#FB2C36` does not select `#fb2c36`.

## API

### hx-color-swatch-picker

#### Properties

| Property      | Attribute  | Type                                   | Default        | Description                                                                                                                                                                      |
| ------------- | ---------- | -------------------------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `name`        | `name`     | `string`                               | `""`           | Name submitted with the form                                                                                                                                                     |
| `value`       | `value`    | `string`                               | `""`           | Value of the selected `hx-color-swatch`                                                                                                                                          |
| `layout`      | `layout`   | `"horizontal" \| "vertical" \| "grid"` | `"horizontal"` | `horizontal` wraps on several lines if needed, `vertical` stacks the swatches, `grid` arranges them in a square                                                                  |
| `size`        | `size`     | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | —              | Size of the swatches, from `xs` 1rem to `xl` 3rem. The gap follows, from 0.5rem to 0.75rem. Without it, `--hx-size-color-swatch-picker` and `--hx-gap-color-swatch-picker` apply |
| `disabled`    | `disabled` | `boolean`                              | `false`        | Prevents user interaction                                                                                                                                                        |
| `required`    | `required` | `boolean`                              | `false`        | Marks the group as required for form validation                                                                                                                                  |
| `invalid`     | `invalid`  | `boolean`                              | `false`        | Marks the field as invalid without displaying a message                                                                                                                          |
| `focusTarget` | —          | — (read-only)                          | —              | The swatch that receives the focus (read-only)                                                                                                                                   |

#### Events

| Name     | Description                      |
| -------- | -------------------------------- |
| `input`  | The user selected another swatch |
| `change` | The user selected another swatch |

#### Slots

| Name      | Description                    |
| --------- | ------------------------------ |
| (default) | The `hx-color-swatch` elements |

#### CSS custom properties

| Name                            | Default    | Description              |
| ------------------------------- | ---------- | ------------------------ |
| `--hx-size-color-swatch-picker` | `2rem`     | Size of the swatches     |
| `--hx-gap-color-swatch-picker`  | `0.625rem` | Gap between the swatches |

#### CSS parts

| Name       | Description                 |
| ---------- | --------------------------- |
| `swatches` | The wrapper of the swatches |

### hx-color-swatch

#### Properties

| Property   | Attribute  | Type      | Default | Description                                                          |
| ---------- | ---------- | --------- | ------- | -------------------------------------------------------------------- |
| `value`    | `value`    | `string`  | `""`    | Color of the swatch, as a hex, `rgb()`, `hsl()` or `oklch()` string  |
| `label`    | `label`    | `string`  | `""`    | Accessible name of the swatch; defaults to `value`                   |
| `disabled` | `disabled` | `boolean` | `false` | Prevents selecting the swatch                                        |
| `selected` | `selected` | `boolean` | `false` | Whether the swatch is selected (set by the `hx-color-swatch-picker`) |

#### CSS custom properties

| Name                       | Default                 | Description                 |
| -------------------------- | ----------------------- | --------------------------- |
| `--hx-size-color-swatch`   | `1.25rem`               | Size of the swatch          |
| `--hx-radius-color-swatch` | `var(--hx-radius-pill)` | Border radius of the swatch |

#### CSS parts

| Name     | Description                                    |
| -------- | ---------------------------------------------- |
| `base`   | The swatch wrapper, scaled on hover            |
| `swatch` | The preview of the color, ringed when selected |
| `check`  | The check of the selected swatch               |
