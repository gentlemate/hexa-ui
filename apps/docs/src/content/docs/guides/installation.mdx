Onent UI is distributed as ES modules. It is meant to be used with a bundler such as Vite, which resolves its dependencies (`lit`, `lucide`, `@floating-ui/dom`).

## Setup

<Steps>

1. Install the package.

    <Tabs syncKey="pkg">
        <TabItem label="pnpm">
            <Code code="pnpm add onent-ui" lang="sh" />
        </TabItem>
        <TabItem label="npm">
            <Code code="npm install onent-ui" lang="sh" />
        </TabItem>
        <TabItem label="yarn">
            <Code code="yarn add onent-ui" lang="sh" />
        </TabItem>
    </Tabs>

2. Import the design tokens once, at the root of your app. Components read their colors, sizes and fonts from these `--oui-*` custom properties.

    ```js
    import "onent-ui/theme.css";
    ```

    Or from a stylesheet:

    ```css
    @import "onent-ui/theme.css";
    ```

3. Import the components. Each import registers the custom elements it contains.

    ```js
    // Import all the components
    import "onent-ui";

    // Or import only the ones you use
    import "onent-ui/button";
    import "onent-ui/input";
    ```

4. Use them in your markup.

    ```html
    <oui-button>Button</oui-button>
    ```

</Steps>
