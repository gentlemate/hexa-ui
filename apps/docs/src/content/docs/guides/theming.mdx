Every component is styled from `--oui-*` custom properties defined in `onent-ui/theme.css`. Custom properties inherit through the Shadow DOM, so overriding a token is enough to restyle every component that uses it.

## Global theme

Override tokens on `:root`, in a stylesheet loaded after `onent-ui/theme.css`. Colors have a light and a dark value: define both, with `:root` for light and `:root.dark` for dark.

```css
:root {
    --oui-primary: oklch(0.205 0 0);
    --oui-primary-foreground: oklch(0.985 0 0);
    --oui-radius-control: 0px;
}

:root.dark {
    --oui-primary: oklch(0.922 0 0);
    --oui-primary-foreground: oklch(0.205 0 0);
}
```

:::caution
`:root` and `.dark` have the same specificity. A color overridden on `:root` only, after `theme.css`, also wins over the dark value: use `:root.dark` for the dark one.
:::

## Design tokens

### Colors

Each color has a `-foreground` pair for the content placed on it.

| Token                                            | Usage                                                                      |
| ------------------------------------------------ | -------------------------------------------------------------------------- |
| `--oui-background` / `--oui-foreground`          | Page background and default text, switch tracks (foreground at 15%)        |
| `--oui-surface` / `--oui-surface-foreground`     | Cards, modals, drawers, popovers, dropdowns, select and date picker popups |
| `--oui-primary` / `--oui-primary-foreground`     | Primary actions                                                            |
| `--oui-secondary` / `--oui-secondary-foreground` | Secondary actions                                                          |
| `--oui-muted` / `--oui-muted-foreground`         | Subdued backgrounds and text, tab lists, progress and slider tracks        |
| `--oui-accent` / `--oui-accent-foreground`       | Hovered and highlighted items, skeletons                                   |
| `--oui-destructive`                              | Destructive actions and errors                                             |
| `--oui-border`                                   | Borders and separators                                                     |
| `--oui-field`                                    | Field backgrounds                                                          |
| `--oui-ring`                                     | Focus rings                                                                |

### Radius

| Token                  | Default   | Used by                                                                                                                                                                         |
| ---------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--oui-radius-control` | `0.5rem`  | `oui-button`, `oui-tabs`, the days of `oui-calendar` and `oui-range-calendar`, the close button of `oui-modal` and `oui-drawer`                                                 |
| `--oui-radius-field`   | `0.5rem`  | `oui-input`, `oui-textarea`, `oui-select`, `oui-date-field`, `oui-number-field`, `oui-color-field`, `oui-date-picker`, `oui-date-range-picker`, `oui-color-picker`              |
| `--oui-radius-panel`   | `0.75rem` | `oui-card`, `oui-modal`, `oui-accordion`, `oui-skeleton`                                                                                                                        |
| `--oui-radius-popup`   | `0.5rem`  | `oui-popover`, `oui-tooltip`, `oui-dropdown`, `oui-select`, `oui-date-picker`, `oui-date-range-picker`, `oui-color-picker`                                                      |
| `--oui-radius-option`  | `0.25rem` | `oui-dropdown-item`, `oui-select-option`                                                                                                                                        |
| `--oui-radius-pill`    | `9999px`  | `oui-badge`, `oui-progress`, `oui-slider`, `oui-switch`, the sliders of `oui-color-picker`, the swatches of `oui-color-field`, `oui-color-picker` and `oui-color-swatch-picker` |

### Sizes and spacing

| Token                   | Default   | Used by                                                                                                                                                            |
| ----------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--oui-height-control`  | `2.5rem`  | `oui-button`, `oui-tabs`                                                                                                                                           |
| `--oui-spacing-control` | `0.75rem` | `oui-button`, `oui-tabs`                                                                                                                                           |
| `--oui-height-field`    | `2.5rem`  | `oui-input`, `oui-select`, `oui-date-field`, `oui-number-field`, `oui-color-field`, `oui-date-picker`, `oui-date-range-picker`, `oui-color-picker`                 |
| `--oui-spacing-field`   | `0.75rem` | `oui-input`, `oui-textarea`, `oui-select`, `oui-date-field`, `oui-number-field`, `oui-color-field`, `oui-date-picker`, `oui-date-range-picker`, `oui-color-picker` |
| `--oui-spacing-panel`   | `1.25rem` | `oui-card`, `oui-modal`, `oui-drawer`                                                                                                                              |
| `--oui-spacing-popup`   | `0.25rem` | `oui-dropdown`, `oui-select`, `oui-date-picker` and `oui-date-range-picker` (via `--oui-spacing-calendar`)                                                         |
| `--oui-height-option`   | `2rem`    | `oui-dropdown-item`, `oui-select-option`                                                                                                                           |
| `--oui-spacing-option`  | `0.5rem`  | `oui-dropdown-item`, `oui-select-option`, `oui-dropdown-group`, `oui-select-group`                                                                                 |

See [`theme.css`](https://github.com/gentlemate/onent-ui/blob/master/packages/onent-ui/theme.css) for the full list and default values.
